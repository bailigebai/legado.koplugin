## 解压安装与升级

1. 确认设备已安装且能正常运行 KOReader。
2. 完全退出 KOReader。升级前备份原有设置和阅读数据。
3. 解压安装包，将整个 `legado.koplugin` 文件夹复制到 `koreader/plugins/`。
4. 确认路径为 `koreader/plugins/legado.koplugin/main.lua`，不要多套一层文件夹。
5. 重启 KOReader，从 **工具 → 书源阅读** 进入。

Kindle 常见插件路径为 `/mnt/us/koreader/plugins/`，以设备实际目录为准。升级只替换插件程序目录，不要删除 KOReader 数据目录中的 `legado/`、`settings/legado.json`、`settings/legado-license.json` 或阅读数据库。

## 功能与使用

- **书源管理**：进入“工具 → 书源管理”，从本地 JSON 或地址导入自备书源，可查看兼容性及管理启停。
- **搜索与发现**：按书名、作者搜索，支持按已选书源查找；有发现规则的书源可按分类浏览。没有书源时会提示先导入。
- **书架**：收藏图书、分类、查看目录和保存阅读进度。
- **阅读与换源**：提供 KOReader 原生阅读与独立阅读界面，可在设置中切换；支持章节目录、匹配书源、章节缓存与后三章预读。侧栏目录每页 15 章，按需懒加载，可设置在左侧或右侧；另含书签、字体、配置页。轻点正文右侧 1/4、纵向 1/16～3/16 区域打开。
- **下载**：生成 EPUB，支持下载任务的取消、重试和恢复，具体可用性取决于书源规则与网站响应。
- **阅读回顾和小票**：这两项展示功能需要兑换码激活；普通书架、导入、搜索、下载及阅读无需因此激活。首次激活需联网绑定设备，之后使用本地验证。

本插件不是 Android Legado 的完整移植，不能保证任意书源都兼容。完整使用说明、已知边界和故障排查见安装包内 `README.md` 与 `docs/`。

## 卸载与数据

完全退出 KOReader 后删除 `koreader/plugins/legado.koplugin/` 即可移除程序，设备上独立保存的书源、书架、阅读进度和下载内容不会因此自动删除。不要为解决安装错误直接删除数据库。

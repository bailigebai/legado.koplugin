# KOReader 书源阅读插件

`legado.koplugin` 是面向 KOReader 的书源阅读插件项目。

**当前仅建立项目和提供介绍，暂不发布安装包、源代码或内置书源配置。** 相关内容正在进行版权与发布范围核查；本仓库目前没有可下载、可安装的版本。

## 功能介绍

已开发版本包含书源导入、图书搜索、书架分类、章节目录、换源、缓存和 EPUB 下载，以及原生阅读与独立阅读界面。阅读回顾和小票为附加功能。

以上为项目介绍，不代表当前仓库已交付这些功能。书源兼容性和站点可用性取决于规则、网络与网站变化，并非完整移植 Android Legado。

## 安装方式

待完成核查并发布安装包后：

1. 确认设备已安装并能正常运行 KOReader。
2. 完全退出 KOReader；升级前备份原有设置、阅读进度和数据。
3. 解压正式发布的安装包，将完整的 `legado.koplugin` 文件夹复制到 `koreader/plugins/`。
4. 检查最终路径为 `koreader/plugins/legado.koplugin/main.lua`，不要多套一层文件夹。
5. 重启 KOReader，从“工具 → 书源阅读”进入。

目前尚未发布安装包，请勿将本仓库的 Download ZIP 当作插件安装包。

## 发布状态

后续发布范围及时间尚未确定。本仓库目前不包含第三方书源合集、网站配置、小说内容、插件安装包或其解压文件。

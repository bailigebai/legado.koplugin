# 0.7.0 阅读衔接、精确换源与悬浮小票

## 页面衔接与首章

打开插件后保持一层 Legado 背景。搜索框、下载管理及阅读准备页关闭或替换时，不再留下裸露的章节缓存目录。原生阅读器关闭后请求打开文件管理器的路径改为返回本插件书架；仅作用于本插件打开的文档。KOReader 重建插件实例时复用同一应用，避免重复的页面管理器。

书架返回需要确认。取消保留同一书架；确认退出后恢复进入插件前的文件目录。下载管理的返回回到书架，下载操作的返回回到任务列表。阅读启动立即失败或取消时，清理准备页并恢复可操作页面。

新书首次目录只提取前三个有效章节的必要信息，完成第一章文档打开后再安排预读（0.5 秒后）及后台目录（6 秒后）。仍需要下载目录网页、建立网页结构并获取第一章正文；这部分受书源速度影响，不能保证固定秒数。目录继续使用两列 24 章、逐行排列、上下 20 页和顺倒序；后台更新合并到 6 秒一次。

## 站点换源与入口

- 入口：阅读顶栏“切换站点书源”，以及书籍简介“更多 → 切换站点书源”。
- 只显示书名、作者一致的搜索结果，忽略大小写及空白差异；缺作者时明确提示，避免将另一本书当作同书换源。
- 每站保留一个匹配结果，章节数从多到少排列；未知数放末尾。未取完的目录注明“至少 N 章”。章节更多并不保证站点正文完整。
- 列表每 6 秒合并刷新，可在全部搜索完成前选择或返回。选择已取到目录的站点时复用目录，并优先按章节标题恢复位置；取消后迟到的结果不能激活阅读。
- 阅读顶栏删除“切换对应书本”，新增“阅读回顾”和“当前书籍小票”。书架底部改为“书架 / 阅读回顾 / 发现”，保留“搜索添加”入口。

## 小票

回顾的“阅读书籍”中点一本书打开小票。默认没有固定的左上角返回、页面“阅读小票”标题和底部回顾导航。阅读顶栏的“当前书籍小票”直接悬浮在当前正文上，关闭后继续同一阅读页面。

- 默认宽 75%、高 90%；宽度可选 50%～95%，高度可选 55%～95%。字体与封面保持比例，不横向或纵向拉伸。
- 点击屏幕中央、从上往下约 1/4 的位置，显示“返回 / 宽度与高度 / 样式”；点击其他位置隐藏控制栏。
- 三种样式：齿孔阅读票据、封面进度卡、日历胶片。点击底部“短评”编辑保存；阅读票据保留状态与评分操作。
- 尺寸和样式保存到现有设置，短评保存到对应书籍记录；写入失败时保留旧值。
- 当前章节页码来自 KOReader；网络书的整书进度按章节估算。没有统计数据时不虚构剩余阅读时间，也不把单章页数当作整本页数。

## 安装与验收

完全退出 KOReader，解压 `legado.koplugin-v0.7.0.zip` 到 `koreader/plugins/`，更新 `legado.koplugin` 代码目录，保留个人数据库、设置和缓存。

1. 从“工具 → 书源阅读”打开书架，测试搜索、取消、下载管理、返回；中间应保留 Legado 页面。书架返回应弹退出确认。
2. 打开一本新书，等待“正在准备章节”进入正文。阅读顶栏返回书架，再打开书；原生返回键也应回到 Legado。
3. 在简介更多和阅读顶栏分别换站点。确认只出现同书名同作者，返回后仍可继续阅读，章节数更新间隔约 6 秒。
4. 阅读顶栏打开当前小票，点击屏幕上方 1/4 中央调节尺寸、切换三种样式并保存短评。关闭后应仍是当前正文；重启后尺寸、样式和短评保留。
5. 书架底部进入阅读回顾，点书籍小票，返回应保留回顾页签和页码。

本版桌面验证覆盖真实 KOReader 控件、原生关闭后返回流程、启动失败、写入失败、取消和迟到回调；真实网站抽测使用生产 Lua 解析和文档缓存代码，网络与显示环境为开发电脑。实体 Kindle 的触摸、残影、设备耗时和与 Moon 同时启用的完整流程尚未验证，不能宣称已消除所有真机闪退。验收时如仍异常，请保留本次 `koreader/crash.log`。

# v0.10.16 阅读细节深查

## 修正范围

- 目录某页加载失败后，上一页已缓存章节仍可查看。并发目录请求完成不会把其他页留在永久加载状态。
- 目录、书签选章失败会提示原因并保留原阅读界面，不再把章节错误显示成整个目录不可用。
- 跳转书签先校验书源和章节身份。目录尚未加载到目标章时按需补齐；不能拿当前最后一章或同序号的其他章替代。关闭侧栏后的迟到结果不会自动跳章。
- 不完整的书签位置保留原数据并禁止跳转，不让异常字段触发界面报错。
- 字体切换后留在原字体页；最后一项被删除后回到仍有内容的页。本地书籍即使没有目录也能使用侧栏其他功能。
- 设置恢复锁下的临时阅读模式在离线续读时采用一致的位置恢复方式；保留设置异常原文件。

每页 15 章、右上约 1/8 高度唤起侧栏、后三章正文预取及无感阅读窗口复用继续保留。不内置书源，不改变授权规则或删除设备数据。

## 安装与验收

完全退出 KOReader，把安装包内 `legado.koplugin` 替换到 `koreader/plugins/`。不要删除 `settings/legado.json`、`settings/legado-license.json` 或阅读数据库。

1. 目录翻到尚未缓存的一页，断网造成失败后返回上一页，应立即看到原章节；重新联网后可重试。
2. 在后面的章节加书签，回到前面并重新打开书，再从书签跳回；应回到同一章和相近位置。请求途中关闭侧栏，应留在原章节。
3. 在字体列表第二页或第三页切换字体，应留在当前页。打开没有目录的本地书，也应能进入书签与字体页。
4. 切换原生/无感阅读，再离线重进缓存书籍，检查章节及章内位置；当前章停留片刻后连续跨三章，检查预取效果。

## 验证边界

140 组 Lua 行为测试（44,894 条断言）、12 组原生 KOReader 兼容用例（37,875 条断言）通过。36 个 UI 模块兼容检查、官方 SQLite 数据持久化、HTTP 总超时、网页正文到实际 HTML 阅读入口、EPUB 与安装包安全检查通过。主机模拟的 40 次缓存跨章全部复用阅读窗口，关闭后遗留任务为 0。

另完成 500 次跨章、200 次菜单开关、50 次阅读模式切换、50 次休眠恢复的压力测试（1,721 条断言）。关闭后目录对象及后台任务均释放，窗口只剩测试宿主底层。检查中修正了一处既有测试误报：同步操作返回的布尔成功值不是可回收资源，不应放入对象释放断言；对真实目录和异步句柄的回收检查保留。

本轮使用宿主回归测试、KOReader 原生控件与故障注入验证。没有 Kindle 实机日志或物理屏幕计时，不能据此承诺设备零延迟。书源没有返回目录、章节身份已改变或正文未缓存时，会提示失败并保留阅读位置，不会伪装成成功。

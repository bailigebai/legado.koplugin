# 不亦阅乎 v0.10.50 微信随文评论

2026-10-03 开发测试包，包含 v0.10.49 下载修复。尚未发布 GitHub。

## 本次改动

- 无感阅读正文增加随文评论虚线下划线。使用实际排版字形位置，跨行、跨页和跨段保持定位；同一句多个评论只划一次。
- 修正微信原文位置计算：在截取正文和清理 HTML 前，保存原 HTML 的 UTF-16 文本坐标，正确处理标签、实体、换行及字符单位差异；保持正文显示不变。此前缓存的章节没有这项位置数据，升级后需在阅读菜单刷新本章一次。
- 点原句显示对应公开想法，重叠原文范围同时显示；页边“评”仍可使用。与词典词条重叠时，点词条文字查询词典，点虚线或页边“评”查看评论。
- 随文评论复用章节讨论头像卡片及详情，展示姓名、正文、实际赞数/回复数。点击想法看完整正文、回复及点赞者，缺少数量省略；无法下载头像时使用姓名占位。
- 菜单“随文评论”可查看本章已加载评论，每页四张卡片，保留评论预览空间。列表保留原句，返回详情保留筛选与页码；“全部随文评论”清除原句筛选。
- 请求使用后台优先级，每次最多 10 个原文范围、每范围最多 20 条，更多内容点击“加载更多评论”；不自动下载全书评论。关闭和翻章先取消可选评论请求，迟到响应不影响新章节。
- 位置信息达到 4 MiB 缓存上限或 20,000 个文本片段时保留完整正文，并将评论留在列表；不使用旧的去标签坐标猜测位置。实体与换行采用连续扫描，避免长段落阻塞。
- 原句与微信范围同时核对；版本不一致、重复无法确定、跨越未知图片位置时不在正文划线，该评论仍可在列表查看。缺少真实想法标识只显示已取得全文。

## 验收方法

1. 完全重启 KOReader，关于页确认 **0.10.50**，打开微信书籍并使用无感阅读；此前已缓存的章节先在阅读菜单刷新本章一次。
2. 联网打开有随文想法的章节，等待后台加载。点击虚线句子或页边“评”，应只显示对应原文的想法。
3. 点想法查看作者及回复，点“阅读全文”查看原句和完整想法；返回应仍在这句评论列表。没有真实赞数时不显示相关提示。
4. 词典书名词条仍可点文字查询；与评论重叠时可用虚线及页边“评”查看评论。
5. 长句跨行/跨页后标记继续；重复点击、返回、换章及断网后重试，不应翻错页、重新打开已关闭页面或混入上一章评论。
6. 若本章评论很多，可从菜单“随文评论”点“加载更多评论”，返回正文查看新增且核对成功的下划线。

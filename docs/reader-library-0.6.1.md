# 0.6.1 阅读回顾与阅读启动处理

完整阅读回顾、小票、数据含义和操作流程见 [0.6.0 功能说明](reader-library-0.6.0.md)。本版补齐累计页的本周日均（本周七个日期的累计秒数除以 7），回顾面板使用圆角；选中页签和小票状态使用原生灰底，避免矩形反色破坏圆角。

包含阅读启动的异步异常捕获：原生阅读器显示和插件界面初始化成功后才结束准备页，失败回到书籍详情并提供阶段、原因和可取得的代码位置。保留书架、目录、页眉页脚以及旧阅读数据。

## 安装与验收

1. 完全退出 KOReader，解压 `legado.koplugin-v0.6.1.zip`，用其中的 `legado.koplugin` 更新 `koreader/plugins/legado.koplugin`。保留设置、数据库、缓存和下载目录。
2. 书架 → 更多 → 阅读回顾：检查累计、每日、阅读书籍三页签；切换年份、月份、日期和书籍页码。
3. 点击书籍进入小票，改变状态与星级，重新打开应保留。返回仍在原页签、日期和页码。
4. 同一本小说点击开始阅读。若仍失败，打开书籍详情 → 更多 → 阅读诊断，并保留本次报错后的 `koreader/crash.log`。

## 验证边界

实际执行结果见安装包旁的 `verification-0.6.1.md`。预览采用实际 Lua 组件、桌面字体/绘图适配和示例书封、记录，不是 Kindle 实拍。

用户设备本次“文件格式不支持或文件无效”的具体触发原因尚未确认。现存设备日志最晚到 09-06，早于此次报错。桌面文件生成、原生异步流程回归和书源抽测不能替代设备原生排版引擎验证；本版不宣称此真机故障已解决。物理 Kindle 的触摸、墨水屏刷新和与当前其他插件共同运行尚未验证。

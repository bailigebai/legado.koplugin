# v0.10.18 第三期无感阅读界面适配

## 本次调整

- 书籍详情页统一标题为“书籍详情”，顶部增加“更多”入口；封面、作者、来源、章节数、状态和简介继续由插件独立页面展示。
- 有阅读进度的书籍显示“继续阅读”，没有进度的书籍显示“开始阅读”，避免把两种入口混成一个状态。
- 详情页底部保留阅读、目录等主要操作，其余操作集中在顶部“更多”，保持小屏 Kindle 的按钮密度。
- 无感阅读菜单和排版弹窗使用与参考界面一致的中文名称：阅读设置、字体、字号、首行缩进、行距、页边距、动画效果、跨章净屏动画和刷新模式。
- Leko 独立文字阅读器继续负责正文分页；Swipe_Animation 适配层继续按设备能力选择原生 swipe 或软件擦除渐显，不调用 KOReader 文件打开流程。

## 验收

主机回归通过：

- 第三期专项规格、详情页回归、字体和动画规格；
- 全量 144 组 Lua 规格，修正详情页旧测试对固定“开始阅读”文字的假设后通过；
- 原生 KOReader 控件兼容检查和发布包白名单检查。

Kindle 实机的触控命中、墨水屏波形速度和实际残影仍需在设备上验收；主机模拟不能替代这些硬件证据。

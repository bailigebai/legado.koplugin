# v0.10.22 换源崩溃与设置恢复修复

本版修复两类会让 KOReader 退出的问题：

- 搜索结果详情或目录请求同步失败后，已完成请求句柄不会再被保存；切换站点书源、关闭详情页和重复加载都会安全取消。
- 站点书源切换的目录请求、阅读器打开句柄和下游取消都经过异常边界。书源或阅读器失败会返回错误提示，不再穿透 KOReader 事件循环。
- “页眉页脚设置 → 底部进度栏”和“页眉页脚设置”在设置文件恢复锁定时都显示“重试读取”和“备份后重置”，避免用户只能看到 `RECOVERY_REQUIRED`。

## 验证

- Lua 规格：145 组，44,969 条断言，全部通过。
- 新增换源回归：同步详情失败、同步目录失败、待取消句柄抛异常、关闭详情取消异常、阅读器下游取消异常。
- KOReader 真机触摸、网络和闪退仍需在目标 Kindle 上验收；本地兼容检查不能替代真机测试。

安装时完全退出 KOReader，解压 `legado.koplugin-v0.10.22.zip`，只替换 `koreader/plugins/legado.koplugin/`，保留书架、设置、授权和缓存目录。

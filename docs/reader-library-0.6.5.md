# 0.6.5 阅读底部进度栏

阅读中打开顶部右侧的阅读页顶栏，进入“页眉页脚设置 → 底部进度栏”。普通“设置”页也提供同一入口。

- 显示方式：隐藏、仅进度条、进度条＋章节百分比和时间。
- 进度条与其右侧百分比表示当前章节进度；时间表示本章预计剩余阅读时间，复用 KOReader 的阅读速度估算和时长格式。阅读统计关闭或尚无估算时显示“时间待估算”。
- 百分比和时间字号：8～22，默认 12。最小栏高：16～48，默认 24，随设备屏幕缩放。字号较大时会按文字实际高度自动撑高，避免文字被裁掉。
- 上一行的章节名、整书进度与底栏之间留出间距；整书进度继续由“页眉页脚设置”的五个位置独立控制。
- 保存后立即生效，重启后保留。旧版关闭底部进度栏的设置会迁移为“隐藏”。隐藏时释放底栏空间。

使用 KOReader 原生 ReaderFooter、进度控件和文本控件，不另建悬浮窗口。只调整由本插件打开的阅读器实例，不修改原生全局底栏设置表。若 KOReader 已整体停用状态栏，插件会提示先从原生阅读设置中启用它。

## 安装与验收

完全退出 KOReader，将 `legado.koplugin-v0.6.5.zip` 解压到 `koreader/plugins/`，更新 `legado.koplugin` 代码目录，保留个人设置、数据库和缓存。

打开一本书，按上述入口依次切换三种模式。隐藏时最底行消失；仅进度条时不显示右侧百分比和时间；详细模式显示进度条、百分比和预计时间。将字号设为 22、最小栏高设为 16，确认文字仍完整，且不被上方整书进度遮盖。返回正文、翻页并重启 KOReader，确认模式、字号和栏高仍保留。

原生控件桌面预览和自动验证记录在安装包旁的 `progress-bar-preview-0.6.5.png` 与 `verification-0.6.5.md`。实体 Kindle 的触摸、字体和墨水屏刷新效果尚未验证。本版没有更改 0.6.4 的圆角比例。此前设备“文件无效”问题仍需当前 crash.log 定位，不能据此版本的桌面验证宣称真机问题已解决。

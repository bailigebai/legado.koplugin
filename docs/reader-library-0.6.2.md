# 0.6.2 界面圆角调整

按钮统一使用更清晰的圆角：主操作、返回、分页和列表按钮为 16，小按钮为 12，卡片与回顾面板为 14，选中日期为 10，均按设备屏幕缩放。保留原按钮尺寸、点击区域、字体与操作逻辑；书架仍为每页 4×3，目录仍为左右两列共 24 章。阅读小票的票据边缘保留。

完全退出 KOReader，将 `legado.koplugin-v0.6.2.zip` 内的 `legado.koplugin` 更新到 `koreader/plugins/legado.koplugin`，保留设置、数据库和缓存。重启后查看书架、详情、目录与阅读回顾：按钮边角应更圆润，分页、返回与阅读按钮仍可触发。

本次只修改界面样式，不改网络、阅读文件或存储。此前阅读回顾与小票的完整说明见 [0.6.0 功能说明](reader-library-0.6.0.md)，阅读启动处理与尚未确认的设备报错见 [0.6.1 说明](reader-library-0.6.1.md)。

验证记录和实际 Lua 组件的桌面预览在安装包旁：`verification-0.6.2.md`、`rounded-preview-0.6.2.png`。实体 Kindle 触摸和墨水屏显示尚未验证；预览采用示例书封与数据。

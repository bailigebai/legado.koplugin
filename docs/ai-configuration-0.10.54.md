# 不亦阅乎 AI 使用说明 · v0.10.54

## 1. 配置密钥

打开“工具 → 不亦阅乎 → AI 服务”（也可从插件设置进入“AI 服务设置”），先选择 DeepSeek 或小米 MiMo。密钥属于对应服务商，不能互换。

### 直接输入

点击“手动输入 AI 密钥”，填写服务商控制台提供的 API Key，点“保存”。输入默认隐藏；再次打开输入框不会显示已有密钥。每个服务商单独保存，切换服务商不会覆盖另一家的密钥。

密钥保存至 KOReader 数据目录下的 `legado/ai-keys/deepseek.json` 或 `mimo.json`；普通设置只保存文件路径。设备上的密钥文件需要按私人文件保管，不要上传或转发。

### 选择 JSON 文件

在电脑用记事本创建 `ai-key.json`，以 UTF-8 保存，把“替换成你的AI密钥”换成真实 API Key：

```json
{
  "api_key": "替换成你的AI密钥"
}
```

复制文件到 Kindle，例如 `documents/ai-key.json`。在插件先选择服务商，再点“选择密钥 JSON 文件”找到它。

两个服务商也可以共用一个文件：

```json
{
  "deepseek": {
    "api_key": "你的DeepSeek密钥"
  },
  "mimo": {
    "api_key": "你的MiMo密钥"
  }
}
```

选择 DeepSeek 时读取 `deepseek.api_key`，选择 MiMo 时读取 `mimo.api_key`。切换后需分别选一次这个文件。安装包提供 [空白示例](ai-key.example.json)，空密钥不能连接，填写后才可使用。必须使用英文双引号，不能加注释或多余逗号。

手动输入和 JSON 文件是两种可替换的配置方式；最后保存的方式生效。页面会显示“密钥：手动输入”或“密钥：JSON 文件”。JSON 文件负责保存密钥；模型在界面单独选择。

## 2. 切换模型

点击“切换模型”，选择常用模型，或点“自定义模型 ID”填写服务商支持的完整 ID。模型分别记忆，重启后保留。模型 ID 只允许 1～128 个英文字母、数字及 `. _ / - :`，不能包含空格。

| 服务商 | 常用模型 | 默认 |
| --- | --- | --- |
| DeepSeek | `deepseek-flash`、`deepseek-v4-pro` | `deepseek-flash` |
| 小米 MiMo | `mimo-v2.6-pro`、`mimo-v2.6-flash` | `mimo-v2.6-pro` |

模型列表于 2026-10-10 按官方文档核对：[DeepSeek 模型参数](https://api-docs.deepseek.com/api/create-chat-completion/)、[MiMo 模型列表](https://mimo.mi.com/docs/en-US/quick-start/model)。MiMo 旧默认 2.5 Pro 升级为 2.6 Pro；已手动保存的自定义模型继续按选择调用。

“测试连接”和正文“AI 解释”都使用当前模型。配置密钥、切换模型和挑选模板不会发送请求；点击测试或解释时，服务商可能按其规则计费。

## 3. 滑动选字后挑选读书模板

1. 在书源、微信读书或 KOReader 支持选择文字的本地书中，长按后拖动选中一段。
2. 点击“AI 解释”，先核对弹窗中的“已选文字”。无感阅读可先使用“调整起点/终点”修正范围。
3. 点击“提示词模板：通俗解释”，选择需要的模板。返回后仍保留刚才选的原文与自填内容。
4. 可填写“补充要求”，例如“用初中生能理解的话，控制在 200 字以内”。
5. 点击“解释”。等待时关闭窗口可取消；取消后迟到的结果不会弹出。

| 模板 | 适合场景 |
| --- | --- |
| 通俗解释 | 难句、典故、不熟悉的表达 |
| 名词背景 | 人物、地名、作品、术语的背景 |
| 段落总结 | 把一段内容整理成要点 |
| 人物心理 | 分析动机、情绪与人物关系 |
| 文学赏析 | 意象、修辞、节奏与叙述方式 |
| 观点辨析 | 检查主张、证据、前提和反例 |
| 联系生活 | 提炼启发与可行做法 |
| 翻译解读 | 外语、文言、关键词和语气 |

模板只作用于这一次选区；再次选区默认通俗解释。模板要求区分原文与推测、说明不确定信息、避免后续情节；实际回答仍需读者判断。选区上限 4000 字节，补充要求上限 2000 字节。

## 验证与设备验收

自动测试覆盖密钥独立存储、失败保留配置、模型重启记忆、实际请求模型/提示词、选区原文与补充要求保留，以及取消、迟到结果和界面显示失败。原生菜单/按钮检查使用官方 KOReader v2026.07.1 源码。

设备验收：分别配置两家密钥，切换模型后测试连接；在书源、微信及本地书各选一段，换成“段落总结”并补充要求，检查实际结果。无需重新扫码微信登录。

本次没有消耗真实 API 余额做推理测试，也未确认 Kindle 触控实装。图片扫描页的 OCR 和无感跨页拖选尚未实现；本地格式的选字能力取决于 KOReader 的文档支持。

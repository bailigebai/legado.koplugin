# 0.6.0 阅读回顾与阅读小票

## 安装与验收

1. 完全退出 KOReader。解压 `legado.koplugin-v0.6.0.zip`，用其中的 `legado.koplugin` 更新 `koreader/plugins/legado.koplugin`。保留原设置、数据库、缓存和下载文件。
2. 书架 → 更多 → 阅读回顾：三个页签分别显示累计时长、每日时长、阅读书籍。累计页可切年份，日历页可切月份、点日期。每天书籍多于三本时分页。
3. 阅读书籍每页三列两行，共六本。点任意封面打开该书小票；返回仍在原页码。切换页签保留选中月份和日期。
4. 每本书详情 → 更多 → 阅读小票 / 阅读回顾，可查看当前书的记录。小票包含大封面、书名作者、天数、时长、位置、三种阅读状态、装饰条码、五颗评分星和日期。点击状态和星星保存，重新打开仍保留。
5. 打开一本网络小说或本地书，阅读后返回书架再查看记录。暂停/休眠时间不计入；跨午夜的阅读分别记录到对应日期。原来的阅读顶栏、页眉页脚设置和网络章节目录仍可使用。

## 数据含义

阅读时间为阅读界面的停留时间，不根据文字速度推算。0.5.0 的累计秒数继续保留，没有每日数据的旧时间在累计页明确注明，不捏造日历记录。阅读天数按不同日期去重。

网络小说展示实际章节位置；完整目录已知时按章节估算小说百分比，明确标注“约”。目录不全时不显示虚假的整书百分比或整本页数。本地书从 KOReader 获取实际文档页码；取不到时显示未知。状态和星级是手工记录，不更改真实阅读位置。

沿用原有进度存储与封面加载，没有新增插件运行依赖。无封面显示占位图。移除书籍等原有数据删除操作仍按原语义执行，不承诺恢复已被删除的记录。条形码仅作装饰；本版没有图片导出功能。

## 阅读启动错误处理

原来的同步保护无法收到 KOReader 下一次界面循环中的打开异常；新版按本次文档捕获可回传的异步打开和界面初始化失败。等原生阅读器显示、页眉页脚初始化和阅读位置恢复成功后，才结束准备界面。失败时回到书籍详情，提供“阅读诊断”，显示阶段及可取得的 Lua 文件名、行号，不显示网页正文、凭据或完整异常文本。

修复失败路径残留的刷新任务与界面挂接；不再把已经关闭的旧阅读器恢复为正在阅读。底部进度栏设置改为操作 KOReader 实际的 ReaderView.footer。上述错误处理缺口已用原生异步控制流程回归；这不等于确认用户设备本次“文件无效”的原始触发原因。

## 验证边界

安装包旁的 `verification-0.6.0.md` 记录测试命令及结果。四类页面的预览由实际 Lua 绘制组件在桌面生成，书封与记录为示例，非用户数据或 Kindle 实拍。

尚未验证：Kindle 实机触摸、墨水屏刷新，以及与设备当前安装的其他插件共同运行。用户反馈的“文件格式不支持或无效”需要结合本次设备报错日志确认具体触发原因，不能凭旧日志断言已修复。

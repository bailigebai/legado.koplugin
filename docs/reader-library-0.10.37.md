# v0.10.37：统一书架与阅读功能

## 安装

从 GitHub Release 下载 `legado.koplugin-v0.10.37-20260928.zip`，解压后将其中唯一的 `legado.koplugin` 文件夹覆盖到 KOReader 的 `plugins` 目录，完全重启 KOReader。保留用户数据目录和原有设置文件；升级不需要重新激活。

## 使用与验收

1. 打开“工具 → 不亦阅乎”。书架最近读的一本在首页顶部，显示较大的封面和简介；下面是四本封面，下一页开始是 4 列 × 3 行。点击四组功能，子页面可返回原书架页。
2. 打开一本在线书源书籍，详情中选“缓存部分章节”，可跳到截至章，任务应从第 1 章缓存到该章；下载管理显示范围与完成数。整本缓存完成才显示封面右下角“已下载”。断网可重新打开已缓存章节。
3. 打开“找书 → 微信读书”，微信扫码确认后同步书架；在书城搜索、点书籍“开始阅读”，检查历史章节位置和当前书的阅读评论。会话失效时重新扫码。首次真实扫码、付费章节和长书正文需在 Kindle 上验收。
4. 打开“更多 → AI 服务”，分别选服务商，在 Kindle 上选一个密钥 JSON 文件，测试连接。原生阅读划词选“AI 解释”；独立阅读长按正文行。修改补充要求后应出现解释。实际 API 连接及费用取决于用户密钥和服务商状态，桌面测试没有发送真实请求。
5. 打开“更多 → 插件缓存”，核对总量和三类缓存。确认清理后，返回书架检查书、进度、授权与导出 EPUB 仍在；离线章节清除后“已下载”角标消失。当前阅读的书受保护，运行中的下载需要先取消或完成。

## 已验证与限制

桌面自动规格覆盖导航、扫码会话模拟、目录与正文分片、历史位置、书城、评论、AI 请求构造、两种阅读入口、缓存统计与清理、安装包清单。微信读书真实账号、微信服务接口、Kindle 触控及 AI 真实密钥仍需实机验证。微信读书付费章节受账号权限限制；书源实际网页的目录和正文质量取决于导入规则与站点。项目现有 `discovery_rules_spec.lua` 需要未随仓库提供的 `sources/yuedu-260114.json`，缺失时该项不能执行。

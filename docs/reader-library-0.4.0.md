# 0.4.0 阅读菜单、本地书架与目录修复

## 使用方法

1. 退出 KOReader，把安装包内的 `legado.koplugin` 文件夹放到 `koreader/plugins/`，替换插件代码。保留 `legado.sqlite`、设置、下载与缓存目录。
2. 打开“书源阅读”。书架右上角“本地书架”可切换本地/书源列表，每页仍为 4 列 × 3 行，只显示封面和书名。
3. 在“更多 → 设置 → 添加本地目录”进入 KOReader 原生目录选择器。长按文件夹名字，选择该目录；支持添加多个目录，移除目录仅取消显示，不删除文件。目录内的子文件夹也会扫描。从书架进入设置并更改目录后，关闭设置会打开刷新后的本地书架；阅读中的设置关闭后仍回到正文。
4. 本地书先显示同名 JPG/PNG/JPEG 图片，或 EPUB、PDF 等电子书的内置封面；缺失时自动从已启用书源搜索同名书的封面。搜索列表没有封面时，继续读取同名书的详情页。匹配成功后保留封面地址，下次不重复搜索。没有找到同名书时仍显示“无封面”。
5. 选择一本书进入详情，再点“开始阅读”。联网准备时显示阶段进度，可取消；缓存命中直接打开。
6. 阅读时点屏幕顶部右侧，顶部第一个书页图标为本插件的阅读页签，包含“目录 / 回到书架 / 设置 / 切换书源”。网页书的原生目录入口也进入书源目录，选章节继续在 KOReader 中读；本地 EPUB/PDF 等仍使用文件自己的原生目录。
7. 设置可开关底部进度栏、设置默认书架来源（书源/本地/混合）、管理启用的书源和本地目录，并清理阅读缓存。清理前有确认，会保留正在阅读的书、目录索引、书架、阅读进度、本地原文件和导出的 EPUB；下载进行中会提示先暂停或完成。

## 本次修复

- 首次阅读仅取一页目录；再次阅读先复用有效缓存。首批仅准备前 3 章，目录明确标记为不完整，打开目录或翻到首批末尾时加载完整目录，不再将首批末尾当成全书结束。
- 阅读会话在成功打开后独立于详情页，关闭详情或打开设置不会使后续章节翻页失效。
- 返回书架先关闭菜单，再在下一次界面更新中关闭阅读器并打开本插件。改动只附着在本插件打开的文档，不修改 Moon 或 KOReader 的文件。
- 森林文学原书源规则同时抓取“最新章节”和“正文”。现在该站使用正文分区，通用目录合并同时按章节 URL 去重，避免先打开结局或反复出现同一章。已导入的原书源也适用，无需重新导入。
- 本地封面复用 KOReader 文档接口；请求随书架翻页取消，目录扫描跳过符号链接与 `.sdr` 元数据目录。

## 验证范围与限制

自动回归覆盖首批/全量目录、跨目录页续读、原生菜单接线与布局、设置持久化、取消异步请求、本地扫描、封面匹配和缓存清理边界。原生菜单与布局使用 KOReader v2026.07.1 源码在桌面 LuaJIT 中运行，平台屏幕和字体等服务使用模拟实现。

真实书源通过原项目的 JSON 集合执行生产 Lua 解析代码；详细网络结果另附安装包旁的 `verification-0.4.0.md`。网站网络会波动，首轮正文分页曾超时，不能把样本成功视为所有 919 个书源都可用。

**尚未验证** Kindle 真机上的触摸、电子墨水刷新、内置 EPUB 封面解码以及与用户所装 Moon 版本同时运行。请按上面的 2–6 步验收。原生状态栏若被 KOReader 整体停用，需要先在原生设置启用，插件会给出提示。

网页目录使用插件的在线目录接入原生“目录”入口；正文仍按章生成 HTML，由 KOReader 排版。不会在首次打开时下载全书，也没有伪造整本书的页码。整本离线 EPUB 可使用原有下载功能。

本地目录扫描最多 8 层、10000 本，超出会显示提示。封面仅自动采用同名（有作者信息时还校验作者）的结果，不保证每本本地书都能匹配到封面。

# 不亦阅乎 v0.10.46 设备测试包

2026-10-03。用户要求先安装当前已完成的开发更新，用于设备验收；此版本尚未发布 GitHub。

## 本次改动

- 右上角选择书源、微信读书或本地书架后，保存为首页书架；退出及重启后恢复。临时进入其他书架不覆盖选择。
- 设置页显示实际首页选择。保存失败时提示并保留旧文件，本次切换仍可使用；重试成功后取消临时提示。
- 混合书架选择书源后立即切换，不再出现当前画面与保存类型不一致。
- 无感阅读的微信末页显示“章节讨论 · 本章热门想法”和首条返回想法的点赞数；展开查看各条正文和点赞数。约预留两行高度，异步回包不重排正文。跨章、关闭及切换账号取消旧请求，失败提供重试。

保留 v0.10.45 的微信图片、跨章错误修复、缓存、阅读进度及授权。整本书评仍在书籍详情。

## 验证边界

开发代码经过完整 Lua 回归、官方 KOReader 和 SQLite 契约检查、独立审查。安装包另做结构、版本和启动依赖检查；安装后读取设备插件，与包内文件逐个比对。实机触控、重启恢复、真实账号讨论及墨水屏显示需按下列步骤验收。

章末列表读取微信网页的本章热门想法，可能包含随文想法；首条赞数不是本章总点赞。网络、离线或协议错误不会显示成“没有讨论”。

微信自动词条的位置和原说明尚未取得；下划线词条、官方说明/AI 分析及特殊字体仍未实现，不能将此测试包视作整套富文本功能完成。

## 设备验收

1. 完全退出并重启 KOReader，打开“工具 → 不亦阅乎”，在“关于”确认版本 **0.10.46**。
2. 右上角切换到微信读书，退出插件再进入，确认仍是微信书架；完全重启 KOReader 后再确认。
3. 对书源和本地书架各重复一次，首页应恢复最后选择，不需要在设置页另选默认来源。
4. 联网开启无感阅读，打开微信书籍，翻到本章最后一页，点击“章节讨论 · 本章热门想法”；查看正文与各条点赞数，关闭回到原阅读页。
5. 继续翻下一章，确认正常翻章；讨论网络失败时可重试，正文仍可翻页。
6. 在《油炸绿番茄》中从“作者简介”翻到“献词”，确认插图仍显示，再翻到“致谢”。

若出现错误，保留提示截图和同次 `koreader/crash.log`。安装备份及文件比对结果保存于开发机的忽略目录，不包含在安装包内。

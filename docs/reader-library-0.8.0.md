# 第一期 v0.8.0

在 v0.7.2 上增加六款小票，共十五款：展览入场券、阅读护照、胶片联系表、阅读档案、阅读时间轴、极简书签。

章节剩余三页时确保下一章预取；到章尾复用正在下载的请求，完整正文及阅读文件提前准备。预取设为 0 则关闭自动预取。慢网络尚未下载完成时仍需等待剩余时间。

阅读顶栏 → 设置 → 阅读背景，可选择本地图片或目录，调整等比大小、上下位置与左右偏移，默认空白。目录按文件名选择第一张支持的图片；支持 PNG/JPG/WebP，单文件不超过 8 MB。建议使用接近屏幕分辨率的图片。读取失败显示错误并恢复空白。

书架 → 更多 → 编辑分类，以及设置内的分类管理，均按列表逐项添加、删除。书籍详情内可勾选分类。删除分类会解除关联，书籍保留；删除前有确认。

## 安装与验收

完全退出 KOReader，解压本期完整包并覆盖 `koreader/plugins/legado.koplugin`，保留 `settings/legado` 数据，再重启。无需先安装旧版本。

1. 打开小票顶部四分之一控制区，逐个选择六个新样式、调整宽高、重开确认保存。
2. 预取设 3，读到剩余三页并连续跨章；慢源应继续同一请求，断网时已缓存章节可读。
3. 选一张方形背景，调整上下/左右/大小，确认不变形，再恢复空白。
4. 更多中新建分类，给两本书勾选，再删除分类；书仍保留，退出分类回到书架。

电脑端检查覆盖原生控件接口、页面事件、SQLite 批量回滚及文件打包。Kindle 真实网络延时、残影与触控体验需要以上步骤实机验收，不能由桌面测试代替。

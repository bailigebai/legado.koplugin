# 不亦阅乎 v0.10.43

2026-10-03。

## 本次修复

- 修复微信原生随文评论的调度异常。KOReader 注册显示模块后会覆盖模块的 ui 字段，旧代码误用该字段调用界面管理器，造成 `scheduleIn` 不存在；改用独立管理器引用。
- 章节关闭会取消待执行的评论定位；晚到任务不会读取或重画已关闭文档，重复关闭不重新调度。
- 跨章失败显示错误代码、失败阶段及安全的 Lua 文件位置，日志新增 `[LegadoReadFailure]`。不展示或记录原始错误正文、帐号凭据和章节内容。
- 保留 25 元售价提示、已有授权，以及缓存、书架、微信图片和随文评论功能。

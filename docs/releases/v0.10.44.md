# 不亦阅乎 v0.10.44

2026-10-03。

## 本次改动

- 无感阅读直接显示微信正文中的插图，按原文顺序图文混排；大图等比缩小或移到下一页。支持纯图片、连续图片、保存图片页进度、横竖屏重排。
- 图片章节不再强制原生阅读，保留用户手动切换。已缓存图片可离线读取；两种模式使用图片实际所属的缓存目录。
- 分页及章节预排版只持有图片路径和尺寸，当前页面使用真实宿主 ImageWidget；替换、失败和关闭释放图片位图。
- 修复合法 EPUB 相对图片地址 `../Images/<文件>` 触发 `INVALID_INPUT / 微信图片地址不受信任`。采用微信官方网页的固定书籍资源路径，保留主机、远程书籍 ID 和路径检查。
- 对旧 EPUB 中 `../Images/note.png` 携带引用文字的标签，以安全的行内注释保留文字。现场图标公开地址返回 404，正文带参考文献；此处理是兼容判断，未声称它符合微信新脚注标记规则。

## 验证与边界

开发回归覆盖图文顺序、图片分页前进与结束、文字评论原文偏移、恢复、模式切换、离线目录、图片内存及失败保留旧页。图片组件测试执行 KOReader v2026.07.1 的真实 Lua ImageWidget，桌面替代 native 解码；不能替代 Kindle 的真实 C 解码和显示。

192 项 Lua 测试、48,312 条断言全部通过；12 项官方宿主契约、37,894 条断言及官方 SQLite 检查通过。独立审查发现的属性识别、nil 解码失败、普通书源原生阅读和透明图片边界已补复现测试并修复。

已连接设备上的旧版本先完整备份，再逐项替换插件代码；重新读取的 145 个文件全部与本版安装包一致。安装包 SHA-256：`a1bc261ef1f63dc9b42c2616f4601953e529b0b7570f8922aada4790a8413c7e`。这个验证只确认安装文件，不确认用户实际阅读效果。

官方图片路径规则来自微信阅读页加载的 [官方网页 JS](https://cdn.weread.qq.com/web/wrwebnjlogic/js/9.cab69770.js)。设备正文包含该相对形式；同章普通 JPEG 的匿名请求返回 200，缺失注释图标返回 404。

## 设备验收

1. 完全重启 KOReader，确认插件版本 0.10.44。
2. 开启无感阅读，打开《生育制度》等含插图章节，检查图片、注释文字及正文顺序。
3. 图片前后翻页、跨章、返回上一页；退出重开确认图片页位置。
4. 已取回的图片章节断网阅读；切换原生，再切回无感。
5. 若仍失败，记录新版错误码和阶段，以及同一次 `koreader/crash.log`。

普通网络图片下载失败仍可能提示错误，未验证所有书源的远程图片规则或每本微信书的资源可用性。保留 25 元售价提示及现有授权、书架、下载、随文评论功能。

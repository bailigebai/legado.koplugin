# 不亦阅乎：整书离线缓存与 EPUB 导出设计

## 目标和验收

现有 KOReader 插件保留内部标识 `legado`、数据位置和授权身份，对外显示名称改为“不亦阅乎”。书源书籍可以选择“缓存整本”供插件断网阅读，也可以继续选择“导出 EPUB”。两类任务共用现有下载管理入口，显示状态、章节数和百分比。只有目录完整、每个可访问章节的正文都已写入专用离线缓存的书，封面右下角才显示“已下载”。本地文件仍由 KOReader 按原格式打开，不参与网络书源缓存。

## 方案比较

1. 只扩展现有 EPUB 任务：改动少，但插件的章节缓存仍会被容量清理，不能保证书架内断网阅读。
2. **推荐：复用任务队列，增加“章节缓存”任务类型。** 专用缓存目录不自动清理，阅读优先读取该目录；EPUB 导出维持原流程。职责清楚，现有持久化和取消/重试能力可以复用。
3. 正文改存数据库：大量正文挤占索引数据库，迁移和回滚成本高，且与现有文件缓存重复。

## 数据与流程

- 默认专用缓存目录为 `${DataStorage:getDataDir()}/legado/offline-cache`。设置中可填写设备上的绝对目录；保存前验证路径、目录可创建和符号链接，实际写入权限在下载时检验。更改在下次完整重启 KOReader 后生效，不移动或删除旧目录。切回旧目录可以重新使用其中的内容。
- `DownloadManager` 新任务标识 `kind="cache"`；旧任务没有 `kind` 时仍按 EPUB 解释。缓存任务强制取完整目录，不把阅读时逐步得到的短目录当全书。目录为空、不完整或含不可下载的 VIP 章节时失败并说明原因。逐章写入专用缓存；全部成功后写入 `complete=true` 的目录并持久化完成状态。失败、取消和重启保留已写章节，重试时复用。
- `ReaderSession` 优先读专用离线正文与完整目录，缺失时回到现有普通缓存和网络流程。EPUB 导出可复用已缓存正文。普通缓存原有容量限制不变；专用离线目录不自动清理。
- 下载页区分“章节缓存”和“EPUB 导出”，显示 `已完成/总章节`、百分比、失败/中断状态。两类任务保持取消、重试和恢复操作。
- 书架封面标记只针对当前缓存目录内已完成的章节缓存任务。校验完成目录和任务状态；当书架目录发现新增章节时撤销标记。目录被外部手动删除或修改后，下次读取失败时按缺失处理，不宣称所有站点都能离线。

## 错误和边界

- 不使用书名作为缓存身份；书 ID 和书源 ID 必须同时匹配。源切换不沿用另一站的下载标记。
- 设置不可用、目录不可写、存储空间不足、网页解析失败或目录不完整时不标记完成，保留已成功的章节供重试。
- 旧 EPUB 任务和文件保持原样；插件目录名、设置文件、设备授权标识、公钥均保持原样。此次不发布、不清理用户文件。
- 自动测试覆盖任务类型、完整目录、断点重试、目录设置、阅读回退、下载页和封面标记。Kindle 触摸、存储路径权限和实际离线阅读仍需设备验收。

# Legado 阅读侧边目录设计

## 目标

在 Legado 的原生 KOReader 阅读和无感阅读两种模式中增加统一的侧边目录。侧栏覆盖在正文上方，打开时不离开阅读页；目录按 24 章一页显示，优先使用当前已经取得的章节，翻到尚未取得的页时才增量请求目录。点击章节后关闭侧栏并复用现有会话导航，切换失败时保留原阅读页和侧栏状态。

## 现状与边界

- 无感阅读已经有 `ReaderSession`、`leko_reader_ui` 和 `openReadingCatalog`，其中网络章节状态存放在 `ReaderSession.active.chapters`。
- 原生在线阅读也由 `ReaderSession` 管理章节；本地文件由 KOReader `ReaderUI` 管理原生目录，不能假设一定存在 Legado 章节列表。
- `ReaderSession:loadCatalog` 已提供可取消的目录请求、目录持久化和并发等待者复用，侧栏不新增网络协议和缓存格式。
- 侧栏只负责显示和分页，不复制正文分页器、书源解析器或授权逻辑。
- 当前没有 Kindle 实机用于本期开发验证，需区分宿主 UI 测试与墨水屏物理刷新。

## 组件与接口

新增 `legado.koplugin/legado/ui/side_toc.lua`，使用 KOReader 的 `WidgetContainer`/`Menu`/`Button` 组件，提供：

```lua
SideToc.new({
    ui_manager = UIManager,
    document = document,
    state = reading_state,             -- 网络/无感/原生在线阅读可用
    native_provider = function() ... end, -- 本地文件或无 Legado state 时使用
    page_size = 24,
    on_load_page = function(page, callback) ... end,
    on_select = function(chapter, callback) ... end,
    on_close = function() ... end,
})
```

侧栏对外只暴露 `show()`、`close()`、`isOpen()`、`refresh()` 和 `onPageChanged(index)`。它不直接调用 `ReaderSession`，由 App/阅读适配器注入 `on_load_page` 和 `on_select`，这样本地文件、在线原生阅读和无感阅读可以共享同一 UI。

## 数据流

### 打开

1. 阅读页顶部栏的“目录”入口调用 App 的侧栏入口，不再打开全屏 `Catalog`。
2. App 计算当前章节索引，使用 `floor((index - 1) / 24) + 1` 定位目录页。
3. 侧栏先渲染 `state.chapters` 中已有数据；已有数据不足时只显示“继续加载目录”，不阻塞正文。
4. 本地文件没有 Legado state 时，通过原生适配器读取已经存在的 KOReader TOC 项目，转换为统一的 `{title,index,position}` 结构。

### 懒加载

- 侧栏翻到已知范围内的页只做本地切换，不发请求。
- 目标页超出已知章节且目录未完成时，调用 `on_load_page(page, callback)`，目标数量为 `page * 24`。
- App 对在线状态调用 `ReaderSession:loadCatalog`，传入 `max_chapters=page*24`；同一目录请求沿用 Session 的等待者复用与取消机制。
- 目录请求期间正文仍可翻页；侧栏展示已有章节和轻量加载状态。
- 普通数据到达后按现有 6 秒节流刷新，首次结果、完成、失败和用户主动翻页可以立即刷新，避免空白等待。
- 页面关闭或阅读会话切换时取消侧栏订阅；迟到的回调只能更新同一代次的侧栏。

### 选择章节

1. 点击章节先暂停侧栏自己的输入，不关闭正文文档。
2. App 使用现有 `ReaderSession:navigate` 或原生文档跳转接口，带上可取消的 `is_current` 检查。
3. 导航完成后关闭侧栏并刷新阅读页；导航失败则恢复侧栏交互并显示具体错误，旧章节保持不动。
4. 当前章节变化时，侧栏更新粗体高亮和所在页；若正在浏览其他页，不强制抢回用户页码，重新打开时再定位当前章节。

## 视觉与交互

- 默认左侧，宽度约为屏幕 42%–48%，保留正文可见区域；提供右侧位置设置。
- 顶部显示“目录”、当前章节标题和关闭按钮；底部显示上一页、`页码 / 总页数`、下一页。
- 目录页每页 24 条，标题过长截断；当前章节加粗。
- 点击侧栏外的正文区域关闭侧栏，但点击章节正文区域仍交给阅读器正常处理。
- 长按/跳页不是首期必要功能；优先保证翻页、懒加载和返回稳定。

## 错误与生命周期

- 无目录数据：显示“当前文档没有可用目录”，不抛异常。
- 目录请求失败：保留已加载条目，显示可重试提示，不跳转文件管理器。
- 章节跳转失败：保留原阅读页、原章节和侧栏，错误交给现有诊断层。
- 关闭、切换书籍、切换阅读模式时统一取消 UI 任务和目录订阅，不能留下定时器或旧回调。
- 侧栏自身异常通过 `pcall` 收口到阅读页错误提示，不能让 KOReader 退出。

## 测试与验收

新增 `spec/side_toc_spec.lua`，覆盖：

1. 初始只渲染已有 24 条，不触发完整目录请求。
2. 已知页本地翻页不请求网络；缺页只请求到目标页所需章节。
3. 同一缺页重复点击只保留一个请求；关闭后迟到回调不更新 UI。
4. 当前章节高亮、页码定位和 24 条分页正确。
5. 选择章节成功关闭侧栏并交给 Session 导航；失败保留侧栏和旧章节。
6. 原生本地 TOC 与无感网络章节均能转换为统一条目。
7. 侧栏连续打开/关闭、切模式和休眠恢复不残留任务。

宿主验收要求：全量 Lua 规格、KOReader v2026.07.1 兼容规格和侧栏回归规格通过。Kindle 实机再验证侧栏覆盖区域、墨水屏局部刷新和弱网下的目录分页耗时。

## 不在本期范围

- 书签、字体预览、配置文件管理等 SideTOC 的其他功能。
- 修改 Legado 书源解析、缓存格式、授权规则和正文排版。
- 将三章合并为单一 KOReader 文档；这属于另一项原生连续文档实验。

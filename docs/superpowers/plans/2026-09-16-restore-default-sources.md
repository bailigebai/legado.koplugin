# 恢复默认书源

目标：安装后默认启用已有 yuedu-260114 合集，保留本地 JSON 和网址导入；短密钥继续只限制小票与阅读回顾展示。

方案：仅恢复按钮需手动操作；启动时在线下载受网络影响；采用内置已有文件并首次本地导入。复用 SourceImporter 和 Settings，初始化成功后记录一次性标记，失败可重试。升级和手动恢复只补充缺失站点，不覆盖用户书源规则、停用状态或来源。首次初始化后删除的来源不会每次重启自动恢复。

沿用之前的展示约定：默认站点可搜索，不显示默认地址和站点列表；管理和发现显示自行导入的书源。手动导入同站点后按自行导入处理。

修改范围：source_importer、source_manager、bootstrap、app、settings、presenter；发布清单、版本和说明同步更新。内置配置为用户此前提供的公开合集，不执行其中任意 JavaScript。

验证：首次启动、本地无网络初始化、默认与自导合并搜索、隐藏范围、手动恢复、去重、升级保留、失败重试、重启保留；全量规格、KOReader 兼容检查、ZIP 白名单和一致性检查。真实网站与 Kindle 触屏可用性不以静态导入检查代替。

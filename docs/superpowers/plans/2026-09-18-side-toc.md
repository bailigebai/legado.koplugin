# Legado 侧边目录实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在原生阅读和无感阅读中加入覆盖正文的侧边目录，按 24 章懒加载分页，章节切换失败时保留原阅读页。

**Architecture:** 新增独立 `side_toc` UI 组件，只接收统一章节条目和回调，不直接依赖书源或 Session。App 负责把 Legado `ReaderSession` 章节、原生本地 TOC 转为条目，并用已有 `loadCatalog`/`navigate` 实现懒加载与跳转。阅读适配器只负责把“目录”动作指向 App 侧栏入口。

**Tech Stack:** Lua/LuaJIT、KOReader v2026.07.1 UIManager、WidgetContainer、Menu、Button、现有 ReaderSession/CacheStore。

**Spec:** `docs/superpowers/specs/2026-09-18-side-toc-design.md`

## Global Constraints

- 每页固定 24 条；打开侧栏不能阻塞正文或立即下载完整目录。
- 网络目录请求必须复用 `ReaderSession:loadCatalog`，不得新增 HTTP、缓存或书源解析逻辑。
- 侧栏关闭、切书、切模式、休眠后不得残留定时任务、请求订阅或旧回调。
- 原生本地文档没有 Legado state 时，只使用 KOReader 已有 TOC；没有 TOC 要显示空状态。
- 不修改授权、默认书源、正文分页器、缓存格式和现有阅读数据。
- 版本递增到 `0.10.13`；安装包不包含测试文件或外部项目源码。

### Task 1: 章节条目分页模型

**Files:**
- Create: `spec/side_toc_spec.lua`
- Create: `legado.koplugin/legado/ui/side_toc.lua`

**Interfaces:**
- `SideToc.new(options)` 接收 `items`, `page_size`, `current_index`, `on_load_page`, `on_select`, `on_close`。
- `SideToc:pageItems(page)` 返回当前页条目，不触发 IO。
- `SideToc:requestPage(page)` 只对缺失页调用一次 `on_load_page`。
- `SideToc:setItems(items, complete)` 合并新数据并保持当前页。

- [ ] 实现纯 Lua 分页和请求代次，不依赖 KOReader UI。

**Files:**
- Modify: `legado.koplugin/legado/ui/app.lua`

- Modify: `legado.koplugin/legado/lib/koreader_reader_ui.lua`

- Modify: `spec/phase3_session_spec.lua`

**Interfaces:**
- `App:openReadingSideToc(state, document)` 创建侧栏并传入统一条目。
- 在线条目：缺页调用 `reader_session:loadCatalog(state, callback, progress, {max_chapters=page*24})`。
- 章节选择：调用现有 `reader_session:navigate(index, request)`；成功后关闭侧栏，失败保留侧栏。
- 原生本地条目：通过 `reader_session.ui:getNativeCatalog(document)` 或等价只读适配器取得 KOReader TOC。

**Steps:**
- [ ] 写失败规格：在线已有 24 条不请求；缺页只请求到目标数量；同页请求复用；选择失败保留旧状态。
- [ ] 在 App 中实现统一条目转换和 generation/cancel 防护。
- [ ] 将旧 `openReadingCatalog` 入口切换为侧栏；保留旧 `Catalog` 模型给非阅读页调用。
- [ ] 在 native/immersive 两个阅读适配器入口接入同一回调。

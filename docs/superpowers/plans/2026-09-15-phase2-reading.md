# 第二期阅读与排版

目标：沿用原生排版，修复正文空尾段、页眉字号和留白，扩大翻页热区，并以整本小说为单位接入 KOReader 统计。

三个方案：修改 KOReader 全局样式/事件会影响其他书；只改每章内容无法解决触摸与统计；推荐在插件当前阅读实例上设置原生能力，并在关闭时清理钩子。独立阅读器第三期再接同一设置/统计接口。

文件：content_cleaner、reader_session 生成HTML、reader_chrome、koreader_reader_ui、settings、app/presenter，新增统计桥。来源规则和性能由另一个独立范围处理。先写回归，再修改并对真实原生接口验证。

验收：中文长段不被不可拆块强制成空页、空白尾段清除但图片保留；小字页眉在首页显示时间；左右对称的五档留白每档有差异；下一页覆盖正文右侧大区域并保留菜单/底栏；统计按书累计且暂停/睡眠不计、写库失败可重试。宿主排版与Kindle物理行为分别报告。

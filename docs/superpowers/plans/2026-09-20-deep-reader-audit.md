# 阅读细节深度检查

以已发布 v0.10.15 为基线，保留书源、授权、缓存和用户数据。先复现再修改，不把主机测试当作 Kindle 实机结论。

## 方案比较

1. 仅重复旧测试：能检查退化，但不能覆盖新侧栏的异步边界。
2. 按使用流程补失败场景、逐项最小修复（采用）：目录翻页、书签、字体、模式恢复各自验证，不改架构。
3. 重写侧栏与阅读会话：影响面过大，现阶段没有依据。

## 阶段与验收

1. 目录状态：加载失败后返回缓存页仍可阅读；多个请求乱序完成不串页；关闭后无刷新。修改 side_toc.lua 及回归用例。
2. 书签定位：懒目录尚未包含目标章时不能跳错；失败不改进度，关闭或换书后迟到结果不跳转。检查 reader_sidebar.lua、app.lua、reader_session.lua，按证据修改。
3. 模式与侧栏细节：临时模式离线恢复位置、无目录文档的其他功能、字体选择后的页码。只修可复现问题。
4. 全量与原生控件检查、跨章压力测试、独立代码审核，打包并按原有发布授权更新 GitHub 最新安装包。

## 能力边界

没有本轮 Kindle 实机日志/计时。无感阅读流畅性通过缓存命中、同窗切换、任务回收来验证；墨水屏物理延迟仍需实机验收。

# 阅读回顾与阅读小票实现计划

**Goal:** 按用户四张参考图实现累计时长、每日时长、阅读书籍三个回顾页签，以及可从每一本书切换显示的票据式阅读小票。

**Architecture:** 复用现有书籍进度存储和 KOReader 原生界面。逐日阅读时长保存在每本书的进度数据中，无新增数据库或网络依赖；回顾聚合这些记录。绘制模块独立接收展示数据，Presenter 负责切换与操作。

**Tech Stack:** Lua/LuaJIT、现有 Storage/SQLite、KOReader widgets/BlitBuffer。

**Spec:** 用户当前 goal 和 `C:/Users/98199/.codex/attachments/fc26f4ff-33b7-4adf-b3b2-46378259ca5d/image-1.jpg` 至 `image-4.jpg`。

## 约束

- 保留原有页眉页脚和返回问题修复；不 reset、提交或删除用户数据。

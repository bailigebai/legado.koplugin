# 授权范围与自行导入书源

后续变更：v0.10.7 恢复默认书源；书源初始化以 `2026-09-16-restore-default-sources.md` 为准，本文授权范围继续有效。

目标：短密钥仅限制阅读小票展示和阅读回顾数据展示。正常阅读继续记录进度和时长，未授权书架没有数量上限。新安装无书源、无默认合集地址或快捷导入；升级保留已导入数据。

方案比较：只修改按钮会漏掉详情和阅读顶栏；统一展示入口校验可复用现有授权并覆盖所有入口（采用）；新增授权服务会扩大改动且无必要。

修改范围：app.lua、bookshelf.lua 移除数量限制；presenter.lua 在小票和回顾展示前校验、更新授权提示并删除默认合集入口；source_manager.lua 移除默认地址和隐藏规则。沿用独立短密钥产品和既有授权存储，不变更线上服务、密钥池或用户数据。

验收：未激活时两种展示均提示授权且不读取展示数据；激活后恢复原操作；未激活可添加超过五本并使用阅读等功能；全新存储为空；本地/网址导入后能在管理、搜索、发现中使用，重启保留。运行 Lua 规格、原生兼容和发布包检查，交付本地安装包；实体 Kindle 验收单独记录。

# AI 密钥、模型和读书模板临时规划书

## 需求与选择

在现有不亦阅乎插件上增加手动输入密钥、按服务商切换模型、选中文字后挑选读书模板，并说明 JSON 格式。继续使用 DeepSeek / 小米 MiMo 及现有异步请求引擎。

| 方案 | 优点 | 成本 | 选择 |
| --- | --- | --- | --- |
| 保留 JSON，增加手动密钥、常用模型及内置模板 | 复用现有流程，离线也能配置 | 少量本地设置与界面 | 推荐并实施 |
| 只保留手动输入 | 界面简单 | 失去电脑编辑文件的入口 | 不采用 |
| 自动拉取模型、增加自定义模板管理 | 更灵活 | 网络等待、额外维护与状态 | 本次不采用 |

## 约束与接口

- 不引入依赖。密钥只存入设备数据目录的独立 JSON，使用现有原子写入；设置仅保存路径，不保存原始密钥。
- `ai_presets.lua` 是模型、提示词与校验的唯一目录。按服务商保存模型；空值表示该服务的默认模型。
- `AI:setManualKey(provider,key)` 返回 true 或 nil/安全错误；`AI:model(provider)` 返回模型 ID；`AI:explain(text,extra,callback,template_id)` 保持原有前三个参数。
- 模板为本次选区选择，不强制保存为默认。选区原文不被模板替换；补充要求在切换模板后保留。确认前不发送请求。
- DeepSeek 默认 deepseek-flash；MiMo 默认升级为 mimo-v2.6-pro，提供 2.6-flash 选项。官方文档核对日期 2026-10-10。
- 自定义模型只允许长度 1～128 的 ASCII 模型 ID；禁止空白、控制字符。
- 配置、选区 UI 各自独立，Presenter 只转发入口。保留等待、取消、旧回调抑制和显示失败重试机制。
- 本轮不调用付费服务做真实推理测试。

# 首页书架类型记忆

## 目标

右上角选择书源、微信读书或本地书架后，将选择保存到现有设置文件。重新进入插件及重启后使用最后成功保存的选择。临时导航到其他书架不修改首页选择。

## 方案比较

| 方案 | 成本与效果 | 决定 |
|---|---|---|
| 只保存到内存 | 改动少，重启后丢失 | 不采用 |
| 扩展原 `shelf_source` | 原值包含混合书架；微信读书使用独立页面，筛选与导航容易混淆 | 不采用 |
| 增加 `home_shelf_mode` | 复用原子写入和损坏恢复；明确区分首页入口与原筛选 | 采用 |

## 范围与验收

- 设置校验、首页入口、右上角选择回调及有关设置界面。
- 三种类型分别切换后，重新构造设置与应用仍进入对应书架。
- 显式临时入口不覆盖选择；点击已经选中的临时书架也可将它保存为首页。
- 保持切换过程中的分页、返回和过期页面回调保护。
- 写入失败时，本次切换可用，用户看到提示，原设置字节保留；重启使用最后成功保存的值。
- 损坏的设置继续走既有恢复流程，不能进入无效书架。

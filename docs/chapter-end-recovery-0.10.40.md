# v0.10.40：章节末尾失败后的重试恢复

## 已验证的故障与改动

- 原生阅读：下一章正文取得成功、异步打开失败后，旧章节恢复为活动状态，但 `end_handled` 仍为真；再次翻页被直接忽略。修复为恢复旧文档时同时解除翻章限制。

改动集中在 `reader_session.lua`，保持现有预取、取消、章节缓存和读者切换事务。测试使用生产会话代码，第二项还使用真实无感阅读组件。

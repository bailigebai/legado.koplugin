# KPW6 手工验收清单

目标：Kindle Paperwhite 第 6 代（KPW6），Kindle 固件 5.19.5，当前稳定版 KOReader。当前设备尚未连接，以下项目尚未执行，全部保持未勾选；执行人应记录 KOReader 版本、日期、书源类型和异常截图。

- [ ] 将 ZIP 中唯一的 `legado.koplugin/` 复制到 `koreader/plugins/`，重启后菜单可见。
- [ ] 从本地导入单对象和数组形式的自有 JSON 书源，兼容性报告顺序正确。
- [ ] 从 HTTPS 导入书源；HTTP 导入显示明文安全警告。
- [ ] 对一个可用书源运行搜索、结果、目录、正文四步诊断，并可中途取消。
- [ ] 多书源搜索可用，单个书源失败不影响其他结果，切换来源正确。
- [ ] 图书加入/移出书架；文字模式与分页封面模式可用，物理按键和触摸焦点正常。
- [ ] 在线阅读可连续跨章，关闭文档后保存章内进度，重开恢复位置。
- [ ] 预取后断开网络，已缓存章节可读，未缓存章节给出明确错误。
- [ ] 目录插入新章后，按章节 URL、标题或邻近序号恢复到合理位置。
- [ ] KOReader 原生字体、字号、行距和背景切换生效，正文没有固定颜色或背景。
- [ ] 整本下载可取消、重试并在重启后恢复；休眠期间不会生成损坏完成文件。
- [ ] 完整 EPUB 能由 KOReader 打开，封面、简介、目录、章节顺序和特殊字符正常。
- [ ] 插件重启后书源、书架、进度、缓存索引与下载记录仍存在。
- [ ] 备份设置文件后制造损坏 JSON；设置页显示保存锁定，重试不会覆盖原字节，输入“重置”后生成不覆盖旧文件的 `legado.json.corrupt-*` 并可重启恢复。
- [ ] “听书”仅提示“听书功能尚未配置”，没有网络或音频副作用。
- [ ] 检查设备日志，确认没有 Cookie、Authorization、查询密钥或章节正文。

完成后请把勾选结果与问题记录保存在单独的测试报告中；不要修改本基线清单来暗示未实际执行的项目已经通过。

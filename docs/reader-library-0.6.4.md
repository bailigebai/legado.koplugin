# 0.6.4 圆角比例调整

按用户指定的比例，以 0.6.2 大圆角版本为基准取约五分之三，并取整：主按钮与返回、分页、列表按钮 16→10，小按钮 12→7，卡片和回顾面板 14→8，选中日期 10→6，均按设备屏幕缩放。按钮尺寸、字体、点击区域、书架每页 12 本和目录每页 24 章保持一致。

完全退出 KOReader，将 `legado.koplugin-v0.6.4.zip` 内的 `legado.koplugin` 更新到 `koreader/plugins/legado.koplugin`，保留设置、数据库和缓存。重启后查看书架、目录与阅读回顾，圆角弧度应介于 0.6.2 与 0.6.3 之间。

本次仅调整三个界面文件的圆角值。验证记录与桌面预览见包旁的 `verification-0.6.4.md`、`rounded-preview-0.6.4.png`。实体 Kindle 触摸和墨水屏效果尚未验证。此前“文件无效”仍待新设备日志定位，详见 [0.6.1 说明](reader-library-0.6.1.md)。

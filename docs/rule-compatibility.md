# Legado 规则兼容说明

本插件实现的是安全子集，不以执行任意脚本来追求与 Android Legado 的完全兼容。书源管理中的兼容性报告会给出 `usable`、`partial` 或 `unsupported`，并按规则字段顺序列出问题；“运行诊断”会依次请求搜索、书籍详情、目录和一章正文。目录检查使用详情中解析出的目录地址；详情失败时停止后续请求。

## 支持的规则

| 类别 | v0.9.0 支持范围 |
| --- | --- |
| 默认规则 | `class.book`、`tag.a`、`id.list`、`children`、`text.文字`；混合 `@` 链；`.0`/`.-1`、离散索引和 `!0` 排除；当前元素 `text`、`ownText`、`textNodes`、`html`、`href`、`src` 等常用属性，其他属性用 `@属性名` |
| CSS | 可带 `@CSS:` 前缀；标签、`#id`、`.class`、属性、后代/子代、位置、`:eq`、`:gt`、`:lt`、`:contains`、`:has`、`:first-child`、`:nth-child(数字/n/n+整数)`，以及文本、HTML、属性取值 |
| JSONPath | 字段、下标、数组、通配符与简单过滤；命名字段递归，如 `$..list[*]`（不含 `$..*`） |
| XPath | 子孙、属性、文本、位置和常用谓词 |
| 组合 | `&&` 合并结果、`||` 回退规则；`##` 使用 Lua 模式匹配清理，不能直接当作 Java 正则使用 |
| 模板 | `{{...}}`，变量 `key`、`page`、`baseUrl`、`result`；字符串/数字、括号及 `+ - * / %`，如 `{{(page-1)*10}}` |
| 受限表达式 | `@js:result.trim()`、字面量 `.replace("旧","新")`、非空字面量 `.split("分隔符")[0]` 及链式组合；同一文法用于字段提取和请求模板，不运行任意脚本 |
| 目录倒序 | `chapterList` 前导 `-`，如 `-.chapters a`；完整目录获取后整体反转并重排章节索引 |
| 安全函数 | URL 编解码、HTML 解码、Base64、MD5/SHA、大小写、trim、replace、相对 URL 解析 |
| 请求 | GET、POST、JSON、表单、自定义 Header、相对 URL、按书源隔离 Cookie、有限分页 |
| 编码 | UTF-8；KOReader iconv 可用时支持 GBK/GB18030 |
| 发现 | 静态 `exploreUrl`：`标题::网址&&标题::网址`、换行分隔或包含 `title`/`url` 的 JSON 数组；结果使用 `ruleExplore`，支持 `{{page}}` |

`ruleSearch`、`ruleBookInfo`、`ruleToc`、`ruleContent` 支持 Legado 常见对象形式。搜索和目录列表保留 HTML 元素供字段规则继续提取；JSONPath 列表保留对象。默认链式文本提取的多个匹配以换行合并；书籍、封面、目录、章节和翻页网址只使用第一个匹配，避免重复链接拼接。正文收集全部匹配段落，空正文报错且不写入成功缓存。

示例：搜索列表 `class.book`，书名 `tag.a.0@text`，书籍链接 `tag.a.0@href`；正文 `id.content@tag.p@text`。索引从 0 开始，负数从末尾计数。示例只是规则格式，不附带网站书源。

目录连续分页默认最多 64 页，正文最多 20 页；调用者可设置更小的目录页数预算，每次规则输出最多 1000 项。请求总时限最多 20 秒，搜索独立超时默认 10 秒；普通请求默认上限 4 MiB，显式请求（含书源合集导入）最多 16 MiB，重定向最多 5 次；这些请求硬上限不会由书源规则提高。历史 SF 2919 章单页目录样本超出规则输出上限，不能据此标为可用。

普通顺序目录可优先获取首批章节。倒序源必须在页数预算内取得完整目录，才能知道哪章是全书第一章，因此不使用启动章节数截断，首次打开可能更慢。若到达页数预算仍有下一页，会明确返回目录不完整、无法定位首章的错误，不把局部最新章节编号为全书第 1 章。完整获取后复用已取得的目录。

受限表达式长度最多 4096 字节、128 个 token、16 层，单个结果最多 4 MiB，split 下标为 0..1000。replace 仅替换第一次出现的字面量，不支持正则或 `$` 替换组；字符串方法的接收值必须是字符串，数值算术不做隐式字符串转数字。递归 JSONPath 整个查询共享 10000 节点预算，深度最多 64，结果最多 1000 项；循环或超限返回解析错误。

## 明确不支持

- 超出上表受限表达式文法的 `@js:`、`<js>`、函数体、动态求值、循环、对象和任意 JavaScript；检测到后返回结构化 `UNSUPPORTED_RULE`，绝不执行。
- WebView、登录 UI、验证码交互、Java/Android API、应用包调用。
- 默认选择器的方括号区间、步长，通用 `An+B` CSS 位置表达式；完整 Java 正则的前后查找、选项、分组替换等语义。Lua 模式匹配与 Java 正则不兼容时需改写规则，静态扫描不能保证自动识别所有差异。
- 脚本生成的发现分类、网页渲染后才出现的内容。
- 用脚本访问设备文件、进程、凭据或任意网络目标。
- 依赖上述能力才能完成搜索、目录或正文的书源。

缺少非核心字段可能得到 `partial`；搜索 URL、搜索规则、详情规则、目录规则或正文规则缺失/含危险构造时，对应 capability 会标记为不支持。兼容性扫描只是静态判断，最终可用性仍取决于站点响应、网络、编码和规则数据，因此建议对自有书源运行四步诊断。

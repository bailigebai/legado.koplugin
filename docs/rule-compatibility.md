# Legado 规则兼容说明

本插件实现的是安全子集，不以执行任意脚本来追求与 Android Legado 的完全兼容。书源管理中的兼容性报告会给出 `usable`、`partial` 或 `unsupported`，并按规则字段顺序列出问题；“运行诊断”会依次检查搜索、结果选择、目录和一章正文。

## 支持的规则

| 类别 | v0.1.0 支持范围 |
| --- | --- |
| CSS | 标签、`#id`、`.class`、属性、后代/子代、位置、`:eq`、`:gt`、`:lt`、`:contains`、`:has`，以及文本、HTML、属性取值 |
| JSONPath | 字段、下标、数组、通配符与简单过滤 |
| XPath | 子孙、属性、文本、位置和常用谓词 |
| 组合 | `&&` 顺序规则、`||` 回退规则、`##` 正则净化 |
| 模板 | `{{...}}`，变量 `key`、`page`、`baseUrl`、`result` |
| 安全函数 | URL 编解码、HTML 解码、Base64、MD5/SHA、大小写、trim、replace、相对 URL 解析 |
| 请求 | GET、POST、JSON、表单、自定义 Header、相对 URL、按书源隔离 Cookie、有限分页 |
| 编码 | UTF-8；KOReader iconv 可用时支持 GBK/GB18030 |

目录和正文连续分页最多 20 页。请求总时限为 20 秒、响应正文上限为 4 MB、重定向最多 5 次；这些安全上限不会由书源规则提高。

## 明确不支持

- `@js:`、`<js>`、函数体、动态求值等 JavaScript；检测到后返回结构化 `UNSUPPORTED_RULE`，绝不执行。
- WebView、登录 UI、验证码交互、Java/Android API、应用包调用。
- 用脚本访问设备文件、进程、凭据或任意网络目标。
- 依赖上述能力才能完成搜索、目录或正文的书源。

缺少非核心字段可能得到 `partial`；搜索 URL、搜索规则、详情规则、目录规则或正文规则缺失/含危险构造时，对应 capability 会标记为不支持。兼容性扫描只是静态判断，最终可用性仍取决于站点响应、网络、编码和规则数据，因此建议对自有书源运行四步诊断。

# 第二期 v0.9.0

包含第一期全部功能。本期增加书架“更多 → 检查更新”，进度合并后最多每六秒刷新，返回可取消。搜索单独超时默认十秒，在设置可调；普通阅读请求继续使用原超时设置。

## 阅读

- 页眉与页脚默认 11 号字，可分别调到 8–18；章节首页仍显示时间。
- 阅读顶栏 → 设置 → 左右留白，提供五档对称边距，每档减少至少一列全角文字；沿用每书原生设置保存。
- 正文右侧四分之三区域用于下一页，上下各留出菜单与底栏空间。
- 清理空白尾段与尾部换行；生成的阅读文件不附加页面左右留白，长段落允许跨页，标题不强制另起一页。
- 顶栏增加“阅读统计”。KOReader 原生统计启用且已有统计数据库时，同一小说跨章、连续换源使用同一记录；插件阅读回顾继续独立保存。

统计桥只写已识别的原生数据库结构，不建库或迁移未知结构。数据库忙时保留至多 500 条待写时段，恢复后重试；强退或断电可能丢失尚未写入的统计。显示的统计页数使用一万格进度单位，不是真实排版页数；章节当前页/总页数仍来自阅读器。

## 书源

支持部分有明确边界的表达式、递归 JSONPath、倒序目录；详细支持范围见 `docs/rule-compatibility.md`。复杂 JavaScript、网站浏览器脚本、Java API 不属于本期完整实现范围。倒序目录须先在页数预算内取全再定位第一章，因此首次打开可能较慢；预算不足会明确失败，不使用编号错误的局部目录。

原始 919 源均通过导入/静态分析；静态分类不能代表站点在线可用。2026-09-15 原始集合第 17 源“英文小说网”在电脑网络上通过搜索、详情、目录、正文四阶段；其他失败及网络限制按诊断保留，不能据此宣称全库可读或 Kindle 网络已验收。

## 安装与验收

完全退出 KOReader 后用此完整包覆盖插件代码，保留数据目录，再重启；无需先装第一期。

1. 在当前小说设置左右留白、页眉 9/页脚 11，跨章和重开确认保持；第一页检查时间。
2. 搜索慢站，确认十秒超时后继续其他书源；书架更多检查更新，返回仍是书架。
3. 启用 KOReader 阅读统计并打开一次统计页；读几页、跨章、换源、休眠再恢复，检查同一本小说的统计记录。
4. 测试一章长段落及尾部空行；正文不丢失，末尾没有由空尾段形成的空白页。

电脑端规格、原生 Lua 控件/SQLite 接口、真实网络和打包检查有各自记录。Kindle 字体实际排版、触屏和网络耗时仍需以上实机验收。

# v0.10.11 移除内置书源

本版在 v0.10.10 基础上仅移除自带书源供应入口，阅读和授权功能沿用上一版。

## 改动

- 安装包移除内置书源合集文件和固定合集地址，启动时不再自动导入书源。
- 书源管理移除“恢复默认书源”，保留“从本地 JSON 导入”“从网址导入”。
- 新安装没有书源；发现提示“请先导入书源”。自行导入后仍可聚合搜索、浏览站点分类、查看详情封面、换源和阅读。
- 已有书源统一在管理与发现中显示，方便自行停用或删除。不自动清空、停用或覆盖设备上的旧数据。
- 无感阅读、后三章预取、缓存管理、书架分类、页眉页脚、小票、阅读回顾和短密钥授权保留。已与 v0.10.10 逐字节核对：阅读器、分页器、预读、缓存、网络请求、书籍解析和授权核心实现未修改。
- 附带的历史测试文档不再包含固定合集下载链接；开发回归样本仅留在源码工作区，不打入安装包。

## 安装

1. 完全退出 KOReader。
2. 先把旧 `koreader/plugins/legado.koplugin` 代码文件夹移到电脑备份，再将新 ZIP 内的 `legado.koplugin` 放入 `koreader/plugins/`。这样旧版本的合集文件不会因为覆盖安装而残留。
3. 保留 `${DataStorage:getDataDir()}/legado/`、`${DataStorage:getDataDir()}/settings/legado.json` 及所有阅读数据；不要删除书架、缓存或授权。
4. 重启并确认 **0.10.11**。新安装从“更多 → 书源管理”导入自己的 JSON 文件或网址。

注意：旧版已经写入设备数据库的书源属于现有数据，此次升级会保留，仍可继续使用，并可在书源管理自行停用或删除。移除安装包内置合集并不等于自动清空旧数据库。

## 验收

- 新安装：搜索没有预置站点，发现提示先导入；书源管理只提供两个手动导入入口。
- 手动导入：本地 JSON 和网址各导入一份，查看管理、聚合搜索及发现分类正常。
- 升级：原有书架、阅读进度、字号/边距、预取设置与短密钥授权保持；停用的书源不被重新启用。
- 继续使用 v0.10.10 的无感跨章功能；本次没有改变其已说明的 Kindle 物理刷新及原生逐章打开边界。

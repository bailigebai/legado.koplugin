# v0.10.32 跨章完整画面提交

用户在 v0.10.31 后继续反馈：章内正常，跨章显示旧正文，右侧有黑带；关闭跨章净屏后仍不正确，各种动画都有问题。此前针对提前点击和局部重画中断的保护不足以确认实机故障已经解决。

## 本次处理

- 新章正文和页眉页脚完成替换后，统一交给 KOReader UIManager 绘制和刷新完整页面。跨章不再启动分条、水波或黑带推进任务。
- “跨章整页净屏”开：请求 `full` 整页清屏；关：请求 `partial` 普通整页刷新。宿主自身的刷新计数策略仍可能将普通刷新提升为清屏。
- 首屏尚未绘制时的重复翻页输入不会跳过该屏；完整绘制后下一次点击到第二屏。章内动画、Swipe 固定参数、后三章预取、存储和授权均不改变。
- 沿用原净屏开关的保存字段，所有动画模式都能调整该开关。旧设置不需要重置。

参考 [Swipe 上游处理](https://github.com/koplugin-swipe-animation/Swipe_Animation.koplugin/blob/59dce480c38538976325f7ebc0831e36bc4c6ed4/patches/2-swipe-animation-core.lua)：其章节边界清屏条件成立时跳过分条动画，直接提交整页。这里对独立阅读器的所有章节边界采用整页策略，并未修改宿主的全局动画补丁。

## Kindle 验收

1. 更新后完全退出并重新启动 KOReader，确认插件版本为 0.10.32。
2. 无感阅读 → 阅读设置 → “跨章整页净屏”关闭。翻到章末并进入下一章，检查下一章标题、正文首屏和右边缘。
3. 再点一次应到该章第二屏；向后回上一章和目录选章也应显示对应正文。
4. 开启净屏重复上述操作，应出现一次整页清屏，不再出现黑带推进过程。
5. 切换 Swipe、水波纹、动画关闭分别复验。章内保留原效果，跨章统一整页切换。

若仍出现旧正文，需要同次设备日志、已安装版本以及当前书籍和章节信息继续定位；不要通过删除书源、进度或授权数据来重试。

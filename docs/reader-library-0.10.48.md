# 不亦阅乎 v0.10.48 设备测试包

2026-10-03。继续完善无感阅读中的微信章节讨论，此版本尚未发布 GitHub。

## 本次改动

- 章节想法卡片显示作者头像、名称、正文摘要，微信实际返回的点赞/回复数；数量缺失直接省略，真实 0 保留。
- 点击想法按需加载详情，可展开完整正文，查看其他人的回复与点赞者；回复保留作者头像、名称及回复对象，有实际回复赞数才显示。支持更多回复、更多点赞者和对子回复的展开。
- 头像只加载当前页，复用独立有界缓存，不携带登录头，失败显示姓名首字。返回/换页取消旧图片请求；图片到达局部重画顶层窗口，不重新排版正文。
- 返回详情保留原列表页码；关闭、换章、换账号取消旧请求，失败保留已加载内容并支持重试。
- 词典支持微信部分类型的嵌套释义。微信明确返回无释义或成功空内容时，显示“暂未收录”，不再误报网络或登录失败；真实认证错误仍沿用登录失效提示。

## 证据与验证边界

官方网页源码核对了 `/web/review/single` 与 `/web/review/commentloadmore` 的 GET 参数，以及点赞者、根回复、子回复字段。真实《油炸绿番茄》作者简介中“莉莉蒙”的想法详情返回 2 个赞、1 条回复，并返回回复者与点赞者头像、名称；使用真实响应离线回放核对解析。

设备当前保存的登录凭据在本次电脑探测中返回 `-2012`。匿名详情可读取，但匿名更多回复返回 `-2010`；成功的更多回复和非空子回复仍需有效登录后的实机验收。插件沿用现有自动续期；若仍提示登录失效，请重新扫码。分页失败不会清空已有回复，也不会显示成没有回复。

词典修复依据官方词典组件的 status 与 message 类型结构，并已覆盖无释义、嵌套释义、格式错误及账号切换的自动检查。当前会话不足以实测“巨石糖果山”的实际收录情况，不能保证微信原词典包含这个词条。

此版本不代表此前整套富文本需求已全部完成。原 CSS 类定义、完整混排行内字体/专用中文字体及微信原有 AI 仍待完成；词典背景说明与段落样式继续保留。

## 验收方法

本地检查：210 个 Lua 规格、48,859 条断言通过；传输、实际 HTML 阅读入口、命名空间、EPUB、安装包行为检查通过。官方 KOReader v2026.07.1 的 37 个 UI 模块及运行时兼容检查、12 个原生规格和官方 SQLite 检查通过。独立复审未发现新的 Critical / Important 问题。

1. 完全退出并重启 KOReader，关于页确认 **0.10.48**。如有登录失效提示，在微信书架重新扫码。
2. 开启无感阅读，在《油炸绿番茄》“作者简介”末页点击“章节讨论”：头像和名称应分开显示，缺数量的想法没有“未提供”提示。
3. 点击“莉莉蒙”对应想法，点“阅读全文”核对完整内容；“回复”中可看回复者，点回复可展开全文；“点赞者”中可看实际返回的点赞读者。数字以微信当前实际返回为准。
4. 对有较多回复的想法点“更多回复”，失败时重试；有子回复时点对应回复进入讨论。返回应恢复原想法，再返回恢复列表原页码。
5. 断网或图片失败时仍能查看已加载文字；关闭讨论后继续阅读，翻下一章正常。横竖屏都不能遮挡页脚。
6. 再查询“巨石糖果山”：有释义时显示原说明；微信无释义时显示“暂未收录”。如明确提示登录失效，先扫码，再重试；无释义时可选更短的词语查询。

账号信息、会话及私有取证不进入源码压缩包和安装包。设备安装需先备份，再对新包全部文件读回核验。

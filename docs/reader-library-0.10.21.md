# v0.10.21 章节预取与无感切换

## 本次调整

- 当前章节阅读器完成可见提交后，立即启动下一章正文预取，不再等待下一次 UI 调度循环。
- 下一章请求继续使用 `next` 优先级；第二、第三章保留在同一个有界后台窗口中，完成后写入正文缓存并提前生成原生 HTML 或无感阅读准备记录。
- 保留一个零延迟复查任务，处理同步完成的测试传输、页面位置和取消生命周期；换书、退出、暂停、休眠恢复仍会撤销不再需要的任务。
- 目录跳章、章尾翻页和重复点击继续复用同一个在途请求，避免因立即预取而重复下载同一章节。

## 验收

主机回归覆盖：

- 阅读器提交时下一章请求已经发起；
- 三章预取窗口仍限制并发、按下一章优先；
- 目录选择取消后不取消仍有价值的后台下载；
- 当前章节切换后不重复下载已完成的下一章，并继续预取新的窗口末端；
- 全量 Lua、KOReader 兼容、敏感信息扫描和可重复打包检查通过。

主机测试不能替代 Kindle 的网络、闪存、KOReader 文档重开和墨水屏刷新时间。原生模式提前缓存正文和 HTML 可以消除网络等待，但跨章仍可能受 KOReader `showReader` 和排版引擎耗时影响；无感模式才使用同窗口章节替换路径。

# 第三期 v0.10.0：无感阅读

这是包含第一期、第二期全部改动的完整安装包，无需依次安装旧版本。完全退出 KOReader，替换 `legado.koplugin` 插件代码目录，保留现有数据目录，再重启 KOReader。

## 启用与关闭

网络小说在阅读顶栏点击“无感阅读：启用”，使用独立的纯文字排版界面。独立阅读菜单中的“关闭无感阅读”可切回 KOReader 原生阅读。点击独立正文顶部区域或页面中间可打开菜单。书架“设置”也提供无感阅读开关，遇到首章无法用独立模式打开时可在此关闭。切换发生在同一章，并尽量保留本章大致位置。两种排版的分页不同，切换后的页码或首行不保证完全相同。

无感阅读的“阅读排版”提供字体、字号、行距、左右留白、段间距、缩进和页眉页脚设置。每本书分别保存两套排版：原生阅读使用该书的原生设置，无感阅读保存该书的独立设置；在一种模式调整字号，不应覆盖另一种模式。

本地 PDF、EPUB 等文件继续由 KOReader 原生阅读器打开。无感阅读只处理网络小说的纯文字正文；图文章节会明确提示“本章包含图片，请关闭无感阅读后使用原生阅读器查看完整内容”。它不会为了继续显示而静默删除图片，也不会悄悄切换模式。按提示关闭无感阅读后再打开该章。

## 翻页效果

在独立阅读菜单打开“阅读排版”，点击“翻页效果”依次选择：

| 界面选项 | 行为 |
| --- | --- |
| 关闭 | 直接显示目标页，不运行翻页动画。 |
| 原版翻页 | 使用 Leko 原版路径；设备支持时调用原生翻页效果，否则使用软件分条刷新。 |
| 擦除渐显 | 新页按条带逐渐显现；可调整“动画刷新”和横、竖屏帧延时。 |

“跨章净屏”控制动画开启时的跨章节清屏效果。先使用默认参数检查阅读，再根据实际设备的残影和响应调整；这些效果只作用于独立阅读页面。

## Kindle 验收步骤

1. 打开一本纯文字网络小说，在一章中间启用无感阅读。确认仍是同章、位置接近，上一页、下一页、上一章、下一章和目录跳转都能继续阅读。
2. 在独立阅读中改变字体、字号和左右留白，退出后重开，确认保留。关闭无感阅读，确认原生排版恢复；再启用，确认独立排版也保留。再用另一部小说验证两书设置互不覆盖。
3. 分别试“关闭”“原版翻页”“擦除渐显”，前后翻页并跨章。翻页期间打开菜单、回书架，确认没有停留条带、持续刷屏或旧页覆盖新界面。旋转屏幕后再检查一次。
4. 读几页后打开小票、阅读回顾、阅读统计、目录及设置，再回正文。锁屏/唤醒、退出/重开，确认进度可继续；在可联网时测试重新获取本章与切换站点书源。
5. 打开一个含图片的网络章节，确认明确提示不支持且没有删图继续展示；关闭无感阅读后检查完整图文。启用开关时再打开本地 PDF 和 EPUB，确认仍进入原生阅读器。
6. 回归前两期：普通顺序目录优先首批章节，读近章尾时预取下一章；搜索超时后继续其他书源；书架“更多 → 检查更新”可完成或返回取消。倒序目录仍须在页数预算内取全，不能把最新片段当作全书开头。

电脑端的规格测试、KOReader 模块检查和打包检查只能分别证明对应的软件行为。Kindle 上字体实际效果、大章内存峰值、触摸延时、动画残影、耗电和网络连接，须按以上步骤验收；不把桌面检查当作实机通过。

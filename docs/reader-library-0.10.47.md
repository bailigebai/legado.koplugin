# 不亦阅乎 v0.10.47 设备测试包

2026-10-03。修复 v0.10.46 的实机反馈，按本会话既有授权安装设备并同步原交接目录。此版本尚未发布 GitHub。

## 本次改动与根因

- **书架保存失败**：真实设备设置遗留 `default_sources_initialized` 布尔字段，新校验将其当损坏配置，锁住全部保存。仅迁移这个已确认的旧字段，保留其余设置及授权；未知字段和错误类型仍拒绝，迁移写入失败保留原始文件。
- **章末讨论失败**：官方接口默认返回 500 条、约 763 KB，超过插件 512 KiB 上限。首次请求限定 20 条后实际响应约 30 KB；保留大小上限、账号隔离和取消，不推断未经验证的分页。当前显示首次返回的章节想法，点赞数未返回时标明“未提供”，不编造为零或章节总赞数。
- **词典背景说明**：读取微信官方词典的实际百科或普通释义。无感阅读中书名号内词语出现下划线查询提示，点击查询；长按其他词语也可查询。支持可滚动说明、失败重试、关闭取消、账号与文档隔离。读取真实《纽约时报》返回时，释义字段虽为空，百科背景仍可显示。
- **段落样式**：保留 h1–h6 标题大小、粗细，明确的安全段落字号/对齐、整段强调、引文内缩；按实际字体测量分页和点击位置。常见斜体字族有可用变体时才使用，不用粗体替代斜体。

书名号的下划线是插件提供的可查询提示，不等同于微信自动蓝词位置。没有在后台批量查询词典。保留图片、章节切换、进度、授权、缓存功能及书籍详情外层整本书评。

## 验证证据与边界

实际设备设置已在只读副本中用新代码回放：原有偏好及授权全部保留，书架选择写入和重启读取成功。真实登录响应回放已验证《威姆斯周报》19 条讨论和《纽约时报》词典背景可被当前映射处理。

回归包括旧字段迁移/拒绝/写入失败，真实请求引擎响应大小限制，词典关闭/切换账号/迟到结果/重试/展示失败，实际选字坐标和对齐。打包前执行完整测试、官方 KOReader 契约和独立审查；安装前备份，安装后完整读回字节核验。

这些验证不能替代 Kindle 的触控与字体显示验收。原 CSS 类定义、完整混排行内字号/斜体/专用中文字体尚未恢复；微信原有 AI 查询未接入。此包不代表整套富文本需求已全部完成。

## 最简单的验收步骤

1. 完全退出并重启 KOReader，在“工具 → 不亦阅乎 → 关于”确认 **0.10.47**。
2. 右上角切换微信书架，确认不再提示保存失败；退出再进入、重启再进入，都应保持微信书架。
3. 开启无感阅读，打开《油炸绿番茄》的“作者简介”，点击《纽约时报》内的下划线，看到词条背景说明；返回后停在原页。长按任意短词语，点击“词典说明”再检查。
4. 翻到“威姆斯周报”末页，打开“章节讨论”，查看内容及实际返回的赞数；关闭回到原位置，继续下一章。断网时失败提示可重试，不能显示成没有讨论。
5. 检查正文中的标题和作者小标题大小/粗细是否区分；含图章节图片是否仍正常，横竖屏后下划线仍可点，阅读位置可恢复。

若仍报错，保留提示截图与同次 `koreader/crash.log`。私有取证、授权及会话不进入安装包或 Git。

# v0.10.53：前后拖选与 AI 解释

## 最简单的使用方法

1. 长按想选句子的一个字，手指保持按住，向前或向后拖到另一端，松手。
2. 核对“已选文字”预览。要扩大或缩小范围，点“调整起点”或“调整终点”，再在正文拖动或点到希望的位置，松手后再次核对。
3. 点“AI 解释”，可填写补充要求，也可留空；点“解释”才会发送所选内容。
4. 等待时显示“正在分析”。点击关闭等待提示可取消；返回的解释可以滚动查看。

书源及微信无感阅读支持当前页跨行、跨段、正向和反向拖选。“起点/终点”始终按文字阅读顺序确定，拖过另一端后仍可继续调整。阅读中的拖选和调整不会自动发送网络请求。无感跨页拖选尚未实现，需要跨页选字时可使用原生阅读模式及 KOReader 自身的选区操作。

本地 MOBI、EPUB、PDF 等格式沿用 KOReader 自身的选择功能；插件在选择菜单加入同一个“AI 解释”。格式必须能选出文字；纯扫描图片未提供 OCR。

## 配置和错误处理

在插件“设置 → AI 服务设置”选择服务商和密钥 JSON 文件，设置默认补充要求，并点“测试连接”。普通本地书可从“工具 → 不亦阅乎 → 打开书架 → 更多 → 设置”进入配置。密钥文件由服务商账号提供，不随公开安装包分发。

选区当前限制 4000 字节（中文通常每字约 3 字节），补充要求 2000 字节；过长时提示缩短选区。只发送确认的原文和提示词，不自动带上整本书或额外上下文。

失败时按提示检查密钥、服务余额或网络；频率限制和服务暂时异常可稍后重试。已关闭的书籍、已取消的请求及旧选区不会弹出迟到的结果。打开 AI 页面失败时保留原选区，便于重试。

## 连接电脑 Obsidian

AI 解释和摘录使用同一份拖选原文。想保存句子时点“摘录到 Obsidian”，先存到 Kindle，再用 Wi-Fi 同步。需要电脑 Obsidian 正在运行，电脑和 Kindle 在能互相访问的网络中。

用户指定仓库 `F:\Ob jichu\基础` 的 Local REST API 插件文件与 HTTPS 配置已准备，接收插件尚未启用。完成启用并生成私有连接文件后，把 JSON 和证书一起复制到 Kindle，在“工具 → 不亦阅乎 → Obsidian 摘录 → 配置连接”选择 JSON，再点“测试连接”。当前仍需完成电脑实际写入读回及设备联网验收。

详细配置见 [Obsidian 摘录说明](obsidian-excerpts-0.10.52.md)。

## 验收步骤与证据边界

1. 在书源和微信各选一段，分别向前、向后拖；调整前端和后端，核对原句、标点和段落换行。
2. 本地 MOBI 和 EPUB 各选一段，确认原生选择菜单有“AI 解释”。
3. 提交分析，确认等待提示；取消后继续阅读，确认迟到回答不重新弹出。
4. 关闭书籍或换章后，旧选择菜单不能再次发起分析。
5. AI 设置测试连接应显示结果，配置错误时有明确提示。

桌面测试覆盖实际阅读控件的长按、拖动、松手、端点交叉、跨行跨段、字形宽度、原生入口、取消和异常回包；采用可控请求回包验证流程，没有调用用户付费 AI 接口。Kindle 的实际触摸与联网结果需要设备验收，桌面通过不能替代这些结果。

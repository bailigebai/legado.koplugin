# 0.7.1 小票背景与编辑

阅读回顾 → 阅读书籍 → 点一本书，小票默认铺满白色背景，覆盖后面的阅读记录页面。阅读正文顶栏的“当前书籍小票”仍悬浮在当前正文上。

在“阅读回顾 → 阅读书籍”页底部点击“小票背景图片”，可填写 Kindle 上的完整图片路径，或点击“选择图片”打开 KOReader 文件选择器，长按图片后确认。保存后再点一本书查看效果。支持 PNG、JPG/JPEG、WebP、GIF 首帧和 BMP；路径留空或点“恢复白色背景”即可恢复。图片等比例适应屏幕，比例不同时留白，不拉伸。单张文件上限 8 MB。

图片无法读取或设置写入失败时显示提示并保留旧设置；已经保存的图片后来被移动或删除时，小票回退到白色背景。图片路径和尺寸、样式设置一样会在重启后保留。

点击小票自身从上往下约 1/4 高度的位置，会显示“返回 / 宽度与高度 / 样式”三个按钮。触发区域跟随小票的高度和位置变化。默认宽度为屏幕 75%，宽度范围 50%～95%、高度范围 55%～95%；文字与封面保持比例。点其他位置隐藏控制栏。

短评为空时显示“短评 · 点击编辑”提示。有内容后只显示短评正文，点击正文仍可继续编辑；清空内容后恢复提示。

## 安装验收

退出 KOReader，将 `legado.koplugin-v0.7.1.zip` 内的 `legado.koplugin` 更新到 `koreader/plugins/`，保留个人数据库、设置和缓存。

1. 阅读回顾 → 阅读书籍 → 点书，确认小票背后是白色，没有记录网格和其他按钮透出。
2. 返回记录页，在底部设置一张背景图片，再打开小票；重启后背景仍保留。恢复白色背景也应生效。
3. 将小票高度改成 55%，再点小票自身约 1/4 高度处，确认仍能打开控制栏，返回后保留原记录页。
4. 添加短评并保存，应只见评语，没有“短评 · 点击编辑”；点评语可继续修改。

本次修改集中于 `ui/receipt_screen.lua`、`ui/presenter.lua` 和 `lib/settings.lua`，复用 KOReader 原生图片、输入框和文件选择器。原生控件桌面测试可覆盖布局、保存、错误路径、回退和触发位置；实体 Kindle 的图片解码、触摸及墨水屏效果尚未验证。

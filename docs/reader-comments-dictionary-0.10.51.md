# 不亦阅乎 v0.10.51 评论导航与词典标记纠正

2026-10-07，包含 v0.10.50 的图片、正文评论、下载及缓存修复。

## 本次改动

- 无感阅读章末入口只有“章节讨论”四个字。加载、失败、空列表状态在点开后的页面显示。
- 章节讨论每页四张读者卡片，显示头像、姓名及评论正文；真实赞数/回复数保留，未知值隐藏。头像下载失败显示姓名占位。
- 菜单“随文评论”：原文片段 → 对应读者 → 评论全文/回复/点赞者。相同原文范围聚合，重复文字出现在不同范围时分别保留；返回保留筛选和页码。
- 点正文虚线或页边“评”直接进入对应读者；多段范围重叠时先选择原文，防止混淆对应关系。原文在顶部显示一次，可点击阅读完整原文。缺少可核对的位置时只留在列表，不猜测正文位置。
- 删除按《书名号》猜测的词典下划线。保留用户主动长按选择文字后的“词典说明”。
- 词典错误区分超时、HTTP 状态、服务错误码和返回格式异常；正常未收录不视为网络失败，仅确定登录失效时要求扫码。诊断日志不记录词语、完整回包或登录凭据。

## 验收方法

1. 覆盖更新插件后完全重启 KOReader，关于页确认 **0.10.51**。
2. 微信无感阅读翻到章末，只应看到“章节讨论”；点开后检查头像、姓名、评论正文及回复，不应出现“点赞数未提供”。
3. 阅读菜单打开“随文评论”，先选原文，再选对应读者；依次返回应恢复读者列表、原文列表及原页码。
4. 点正文虚线，应直达该处读者评论；点顶部原文可看完整片段。旧章节没有原文坐标时，在阅读菜单“重新获取本章”一次。
5. 普通《书名》不应自动出现词典实线。主动长按词语，选择“词典说明”；遇到错误应显示实际类型，可重试，断网不能提示一定要扫码。
6. 加载中返回、换章或切换账号后，迟到响应不得重开旧页面；头像失败不影响评论正文阅读。

# 0.6.3 轻微圆角

按用户反馈收小 0.6.2 的圆角：主按钮、返回键、分页、列表按钮和面板为 5，小按钮与选中日期为 4，均按设备屏幕缩放。按钮大小、字体、点击区域及原操作流程保持一致，书架仍为每页 12 本，目录仍为每页 24 章。

退出 KOReader 后，将 `legado.koplugin-v0.6.3.zip` 内的 `legado.koplugin` 更新到 `koreader/plugins/legado.koplugin`，保留设置、数据库和缓存。重启后查看书架、目录与阅读回顾：边角应仅有轻微弧度。

仅调整三个现有界面文件的圆角值。验证记录及桌面预览见包旁的 `verification-0.6.3.md`、`rounded-preview-0.6.3.png`。实体 Kindle 触摸与墨水屏效果尚未验证；此前“文件无效”仍待此次设备日志定位，详见 [0.6.1 说明](reader-library-0.6.1.md)。

# 0.5.0 页眉页脚与阅读记录

## 安装和最短验收路径

1. 完全退出 KOReader。解压 `legado.koplugin-v0.5.0.zip`，把其中的 `legado.koplugin` 代码目录放到 `koreader/plugins/`。保留现有数据库、设置、缓存和下载文件。
2. 从“书源阅读”打开一本小说。点击阅读页面顶部，进入第一个书页图标页签，选择“页眉页脚设置”。每个位置展开后可选择时间、书名、本章当前页/总页数、当前章节、小说进度或关闭。
3. 返回正文，确认选择即时生效；关闭并重新打开小说，选择应被保留。顶部居中显示小说书名，不是缓存文件名。
4. 默认布局按参考图红框：左上时间，顶部居中书名，右上本章页码，左下章节名，右下小说进度。五个位置均可更换内容。
5. 在书架点开一本书的详情，点“更多 → 阅读小票 / 阅读回顾”。两页可以互相切换，返回会回到该书详情。无进度的新书显示未开始；有封面时复用现有封面缓存和加载器。

## 具体行为

- 页眉页脚注册到 KOReader 的 ReaderView（正文绘制区域），不创建新的全屏窗口；原有手势、目录和菜单仍由 KOReader 处理。
- 文字大小为 13 个标准尺寸单位，随设备缩放。左右区域限制宽度，长书名/章节名由 KOReader 截断显示；横竖屏按当前屏幕重新定位。
- 可重排文档在页眉/页脚启用时临时保留至少 26 个标准尺寸单位，页脚位于原生底部栏上方。不会保存为用户的全局页边距；全部关闭时恢复原有边距。
- 页码随正文翻页更新。时间最多每分钟触发一次对应页眉或页脚的局部刷新；菜单或锁屏覆盖阅读器时不主动刷新，退出阅读取消任务并卸载绘制模块。
- 在线书每章仍由独立 HTML 排版。因此右上显示本章真实当前页/总页数；右下按“已过章节 + 本章进度”估算小说进度，并标注“约”。目录尚未完整时显示“目录加载中”，不会把首批 3 章误认为全书。
- 本地 EPUB/TXT 等文档使用 KOReader 书籍元信息、文档进度与原生章节目录；没有章节信息时页码退回整个文档页码。PDF 等固定版式文档的边缘显示尚未在真机验证。
- “更多”条目增加后，详情出错时的诊断入口优先显示，避免被排到后页。
- 修复高分辨率屏幕的重复字号缩放；本地 EPUB 关闭时只在文档释放前保存进度，跳过关闭后的重复保存，避免打断返回书架。

## 阅读回顾和小票

复用插件每本书的进度记录，显示书名、作者、状态、当前章节、小说进度、累计时长、最近阅读时间。小票使用现有详情卡片和封面系统；回顾使用简短统计列表。原有没有时长/完整目录标记的记录会显示零时长或目录待确认，继续阅读保存后更新。

累计时长是本版开始记录的打开阅读时长，排除 KOReader 发出的休眠/阅读暂停区间，包含阅读界面的亮屏停留；不是根据文字速度估算的专注时间。没有倒推历史数据。没有每日图表、评分、装饰条形码或图片导出功能。

## 验证与边界

自动验证覆盖五个位置全部选择、保存失败保留旧值、重开持久化、原生页签接线、章节/小说进度区分、目录未完整、阅读暂停与继续、菜单返回、横屏和标签边界。使用 KOReader v2026.07.1 原生文本组件与菜单代码，桌面平台服务和字体使用模拟实现。

安装包旁 `verification-0.5.0.md` 记录实际命令、测试数量、校验值和本次真实书源样本结果。`reader-chrome-preview-0.5.0.png` 是生产绘制代码生成的桌面布局预览，正文是示例，非 Kindle 实拍。

**尚未验证**：Kindle 真机的触摸、墨水屏刷新、实际排版留白，以及与用户当前 Moon 版本共同运行。请按以上 1–5 步验收。自动测试和单站点样本成功不能证明全部网站都可用。

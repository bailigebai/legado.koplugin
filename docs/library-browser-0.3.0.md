# 0.3.0 独立图书浏览与跨源搜索

## 操作

退出 KOReader，将安装包中的 `legado.koplugin` 文件夹放入 `koreader/plugins/`，更新插件代码，保留个人数据。完整重启后，在“工具 → 书源阅读 → 关于”确认版本为 0.3.0。

1. **搜索**：输入书名后直接搜索全部启用书源。结果会逐步显示，卡片包含封面或占位、作者、简介及匹配的来源数量。可以先打开已找到的书；这会停止剩余查找。需要更多来源时在详情选择“切换书源 → 继续查找来源”。
2. **发现**：点击站点，再选择站点提供的分类，查看图书卡片。返回会回到分类，再回到站点列表。不能执行的分类会保留状态说明；没有分类的站点仍可通过书名搜索。
3. **详情**：独立显示封面与元信息；可查看完整简介、加入或移出书架、查看目录、切换来源、开始阅读、下载整本。搜索/分类列表复用加载后的元信息。书架内只有一个已知来源时，“切换书源”会重新按书名查找。
4. **书架**：收藏和简介保存在插件自己的数据库，封面保存在插件缓存目录。空书架保留“搜索添加”。书源管理保留零收藏的站点以及“导入指定书源合集”。

找书、分类、详情、收藏与封面均由插件自己的模块管理，不依赖 KOReader 文件管理器的图书索引。正文阅读使用 KOReader 的排版和翻页功能。本版移除听书入口。

## 参考

流程参考 `wangyisll1/Legado_Max` 的 SearchModel/SearchViewModel（并发搜索和渐进结果）、item_search.xml（左封面、右元信息、来源数）、ExploreAdapter 与 BookInfoActivity。根据 Kindle 墨水屏改为分页及原生控件；并非将安卓界面或 JavaScript 引擎直接移植。

## 2026-09-10 真实网站检查

使用用户指定的 260114.json 合集和上一版四站适配文件，通过生产 Lua 导入器、BookService、规则解析器、请求处理和诊断代码进行受限网络检查。桌面网络使用 Python，解压使用原生 zlib。

最初部分 HTTP 200 网页因服务器返回 gzip 而解析失败。修复共用请求处理后，以下四站分别通过搜索、详情、目录、首章正文：英文小说网、何以笙箫默、画本阅读、殓师灵异。证据文件为 `dist/search-check-20260910-fixed.json`。

分类通过不等于正文通过。额外测试显示：185 号源当前搜索列表解析失败；286 号源搜索、详情与目录通过，正文依赖动态 JavaScript 请求，当前仍无法阅读。两源的分类配置单独保存为 `dist/legado-discovery-samples-20260910.json`（只调整分组，未改规则），用于分类界面验收；它们不计入四步阅读通过的四站。

另两站初次抽查发生网络错误。全部尝试与失败记录保留在 `dist/discovery-check-20260910.json` 和 `dist/discovery-check-20260910-fixed.json`。每站最多 8 次请求，只检查首个可用分类和一本书，未遍历全站。

919 源逐项离线分类解析未发生未处理异常：375 源有可构造的静态分类、454 源为空或仅标题、19 源 JSON 格式无效、71 源使用顶层脚本。此统计只说明分类结构，不代表网站能访问或书能读。动态脚本、登录及 WebView 仍不支持。

## 验证与边界

新增检查覆盖：跨源渐进合并、失败隔离、取消与迟到回调、查询条件恢复、可点击的早期结果、发现/分类返回、详情更新、收藏持久化、书架重新找来源、阅读错误返回详情，以及解压输出大小和压缩校验。

本轮完整回归：73 个 Lua 测试规格通过、0 失败；命名空间、网络超时与重定向、入口启动、EPUB 结构，以及安装包白名单、重复构建、异常 ZIP 和版本不匹配检查全部通过。最终分页调整后，原生图书界面与首页专项重新运行，63 条断言全部通过。官方 KOReader 固定版本兼容检查覆盖 24 个 UI 模块，通过。

原生布局测试使用固定 KOReader v2026.07.1 的控件代码，桌面字体和图像设备层使用替身。生产控件树实际绘制的三页预览保存在 `dist/library-preview-0.3.0.png`，包括搜索结果、详情和书源管理。预览使用桌面字体与封面占位，不等于 Kindle 实机截图。

用户指定网址本轮再次实际返回 HTTP 200，4,465,023 字节，SHA256 与单独交付的 `sources/yuedu-260114.json` 一致：`8ca6123043aa9d694a65420827ae144c6f498f097688476d40e53d4c44dc29f5`。原版 KOReader LJSQLite3 封装实际保存、关闭重开、逐字段比对及重复导入 919 源通过。

升级包为 `dist/legado.koplugin-v0.3.0.zip`，书源 JSON 单独提供。四个阅读流程通过的适配源为 `dist/legado-sources-adapted-20260908.json`；分类验收用的两源为 `dist/legado-discovery-samples-20260910.json`。可先用这两份小合集检查对应流程，再导入原始 919 源。失败原因在界面和检测报告中保留，不把导入成功等同于规则全部兼容。

**尚未验证**：没有连接 Kindle，未运行 Kindle ARM 二进制。真机触摸、墨水屏刷新、字体与图片解码、设备网络及长期阅读仍需安装后验收。书源规则和网站可用性会变化，不承诺全部 919 网站或全部章节可用。

安装后的最短验收：搜索一本书，确认无需选择书源即显示结果卡片；再在发现页打开一个有分类的站点，检查分类 → 图书 → 详情 → 返回；收藏后重启插件，确认书架仍有该书。

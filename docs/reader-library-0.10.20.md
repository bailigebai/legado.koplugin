# v0.10.20 阅读切换与页脚设置

## 本次调整

- 目录或书籍切换命中缓存时，先完成实际切换再决定是否显示“正在准备章节”页面，避免同步命中路径多一次全屏绘制和关闭。
- 未命中缓存、正在下载或等待 KOReader 阅读器就绪时仍显示插件自己的准备页面，取消和失败回调保持原有生命周期保护。
- 阅读排版的“底部进度栏”新增独立的“阅读进度：启用／停用”开关。停用只隐藏页脚，保留“仅进度条／进度条＋章节百分比和时间”的选择；重新启用后恢复此前显示模式。
- 旧设置仍兼容：只有旧版 `progress_bar=false` 且没有显示模式时才迁移为隐藏；同时存在显式模式和开关时保留两者。

## 验收

主机回归通过：

- `_startReading` 同步完成不再创建临时准备页，异步阅读仍显示准备页；
- 页脚开关的保存、重启读取、当前阅读器隐藏/恢复和显示模式保留均有回归断言；
- 全量 Lua、KOReader 兼容、敏感数据扫描和可复现打包检查需在发布前重新运行。

主机计时只能证明缓存命中路径不重复创建准备页，不能替代 Kindle 的网络、闪存、KOReader 引擎和墨水屏刷新测量。未缓存的远章仍受书源网络和正文排版耗时影响。

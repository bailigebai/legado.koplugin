# v0.10.31 跨章首屏显示修复

## 问题与已确认边界

用户设备表现：章内翻页正常，跨章出现右侧黑带、旧正文，下一次点击直接到下一章第二页。
照片中的页脚已经属于下一章，提示逻辑章节与屏幕提交不同步。本轮电脑未识别到 Kindle，
未取得同次设备日志，也未确认设备安装版本及动画设置；不能认定以下测试场景就是设备故障的唯一触发条件。

生产代码和失败测试确认了两条缺陷路径：

1. `animateEntry` 先提交新章节位置，再异步呈现首屏；此时 `nextPage` / `previousPage`
   会取消动画并继续翻走。跨章净屏的首帧仅有旧内容与右侧黑带，因此提前点击会丢失下一章首屏。
2. 宿主局部重画在绘制前就取消动画、释放完整目标页。如果随后正文或页脚绘制异常，
   补交整页刷新不会执行，仅页脚刷新就可能留下旧正文和黑带。故障注入已复现这条路径，
   但没有证据证明用户设备同次发生了字体或页脚异常。

## 选择与改动

| 方案 | 影响 |
| --- | --- |
| 关闭跨章动画 | 简单，但丢失已有动画功能 |
| 动画结束前忽略所有点击 | 避免跳页，但点击没有及时反馈 |
| 提前点击立即补全首屏；保留可回退的目标画面 | 本版采用，保留动画与及时响应 |

运行代码只修改 `legado/ui/leko_reader.lua`：

- 新章节首屏未提交时，提前前翻或后翻只补全该屏；显示完成后正常翻页。
- 关闭动画时也等待首屏重画；原生动画已同步提交整页时不要求额外点击。
- 发生宿主重画时，成功后才释放动画目标；重画失败则提交保留的完整页面，并继续报告异常。
- 局部重画中断动画后仍补交整个阅读区域，最后由宿主合成上层窗口；正常动画不追加整页刷新。
- 不修改动画几何、固定 Swipe 预设、预取、书源、授权或按书保存设置。

## 验证

- 红测试：提前点击时首屏位置被推进；局部重画失败时可见画面保留旧正文和黑带，两项均先失败后通过。
- 新增 77 条断言：预排版命中/未命中、擦除、固定 Swipe、四种水波效果、关闭动画、原生动画、
  提前前翻/后翻、正常下一页、故障回退、迟到回调、关闭后任务清理。
- 可见面板与工作 framebuffer 分开模拟，检查提交给面板的完整首屏，而非只看内存或页码。
- 现有生产 Session 集成测试补上关闭动画时的实际重画步骤，然后检查跨章和返回上一章末屏。
- `scripts/run-specs.ps1`：150 组 Lua 测试，46,412 条断言；网络、命名空间、HTML、EPUB、打包行为检查通过。
- `scripts/check-koreader-compat.ps1 -Offline`：固定 v2026.07.1 的 36 个 UI 模块契约，
  12 组宿主测试、37,882 条断言，以及官方 SQLite 读写/回滚检查通过。

## Kindle 验收

覆盖安装 v0.10.31 后完整退出并重启 KOReader，不删除用户数据，原授权无需重新激活。
进入原来出错的小说，保持原动画设置，在章节最后一页翻入下一章：

1. 正常点击应显示完整首屏，随后一次点击到第二页。
2. 跨章尚在动画时快速再点一次，应立即显示完整首屏，不跳到第二页；再点才翻页。
3. 前后跨章、预加载命中/未命中、打开目录再返回，检查没有旧正文或黑带停留。

本轮未做物理设备刷新、残影或触屏验证。若仍发生黑带，请保留同次 `koreader/crash.log`、
插件版本和动画/跨章净屏设置，以定位本轮尚未复现的设备路径。

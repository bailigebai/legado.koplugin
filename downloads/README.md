## 安装

完全退出 KOReader，将 ZIP 中的 `legado.koplugin/` 复制到 `koreader/plugins/`，替换插件代码后重启。从“工具 → 不亦阅乎”打开。升级保留用户数据和 settings 目录；本包不含书源、会话、密钥和阅读记录。
